# Writing two requested facts from a pictured page

The previous writer gave 111 exact stopped single answers on 824 multilingual MLQA requests with one predicted excerpt. On 171 of 610 requests missed by four existing policies, the accepted physical spelling appeared among the reader's first eight candidates. We test whether the writer learns to use ranked alternatives when the requested answer has two parts. [Prior measurements](visual_reply_learnability.md)

Each training example combines two human BiPaR questions about the same Chinese novel passage. A local Qwen3-4B supplies two short Chinese clauses. Each must include its own annotated answer exactly once, omit the other answer, and contain additional Chinese text. The writer sees both questions and learns both orders in Chinese and English. Its target joins the two clauses with ordinary punctuation. These checks establish inclusion and order. The teacher can still write an incorrect predication.

Two writers start from the identical bilingual book checkpoint. Both see the whole page. After it come two banks of up to eight distinct ordered excerpts, with at most 60 excerpt cells per question. The candidate uses predicted intervals. The control moves each interval to another start on the same page, preserving its length, rank and separators. A fixed seed, equal supervision, minibatch sizes and matched input lengths isolate excerpt placement. Both fits use the existing next-image likelihood and source pointer. Generation takes up to 48 cells, with a learned stop. The ranking head, writer and teacher serve distinct roles. The teacher is used only offline.

The fixed reading test uses up to 96 passages sampled from the earlier BiPaR validation partition and 12 newly authored pages spanning repairs, books, materials and changing roles. Each page is requested four ways, using Chinese and English in both orders. The new pages and labels are fixed before training. A reply earns order credit when it stops and contains each specified physical fact exactly once in the requested order. We count both orders per language and all four requests per page. Exact clauses on the new pages are an additional stringent check. Fact inclusion alone does not assess the truth of every surrounding word. Report the unchanged parent on the unannotated page, both fits crossed with both bank placements. Consider excerpt conditioning supported only if matched training beats all three shifted comparisons on two-order pages in each test collection. Inspect fixed-index original pixels, including misses. A failure calls for locating whether both facts were retrieved and whether the writer used them. A pass warrants separate testing of factual predications and broader writing before promotion.
