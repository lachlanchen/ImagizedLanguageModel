# Writing after a mistaken glyph prefix

The released translator identified the true pictured source for 90/96 supplied human translations but independently wrote zero credited answers on the same passages. Test one change to learning. Begin both fits at the released role-rehearsal weights. Use the full length-matched 231,337-pair corpus. For a fixed half of the translation directions, give the frozen starting writer a short reference prefix of length zero, four, twelve or twenty-four (shorten to zero if necessary). Allow up to eight greedy glyphs afterwards, terminating the draft at the first stop. Compare the resulting glyphs with prefixes of the remaining reference by unit insertion, deletion and substitution distance. Prefer the least difference in length at a tie and then the smallest reference offset. An optimally aligned reference prefix can be at most twice the draft length because the empty reference prefix is available. Store the physical draft once for both fits. Use the human-aligned reference suffix and its stop as supervision.

In the recovery fit the decoder sees the original prefix, the draft, and then the reference suffix. In the control the draft is replaced by the corresponding reference prefix. Suppress the loss on the intervening draft or aligned reference region. Score the same initial reference positions, suffix and stop in both fits. The other half of directions retain full clean training. Early-stop locations in the draft are recorded; no stop is fed back as ink. This tests recovery on the starting writer's distribution. At inference the two models use their own unassisted feedback and greedy stop. Sequence training with model roll-ins has previously been studied in machine translation. [Leblond et al., 2018](https://arxiv.org/abs/1706.04499)

Match three additional passes, batch membership, learning-rate schedule, actual supervised labels and optimization steps. Monitor output on the existing document-disjoint development partition in both directions. Select among trained passes by highest macro-average stopped, normalized glyph edit similarity across domains (earliest tie). Retain the unmodified start as an additional control. Reserve 24 passages each from four new literary works, previously unused TED test talks and previously unused FLORES devtest article URLs before optimization. Exclude exact train-side overlaps. Test both directions. Use the same masked complete-meaning grader, references, foil, text Qwen comparator and stringent output-stop requirement. Show fixed-order raw answers, recovered complete meanings and losses. Compare whole role families and Noto Serif transfer. Evidence for promotion requires a positive gain over both other visual writers on fresh complete meanings, a positive document-bootstrap lower bound over the matched control, and retention of at least 110/118 complete role families on both typefaces. If this intervention fails, preserve the previous writer and use the measured recovery and free-writing gap to select the next learning change. Limit each fit to three passes, 12 GiB peak allocated memory and one device-hour; use a single serial GPU owner.
