# Summing the edit paths to a pictured sentence

The glyph writer currently learns one recorded edit alignment. Different paths can yield the same answer image. For example, a copied source glyph and a redrawn duplicate can produce identical pixels. An objective that sums the probability of every compatible path can train from the observed answer while leaving its edit alignment latent. This is one route to learning an inserted phrase from its pictured context. The recent allowance experiment shows why merely giving the model room to insert more writing is insufficient. [Insertion experiment](edit_diversity_result.md) · [Recurrent neural transduction](https://arxiv.org/abs/1211.3711)

Let state $i,j$ depend on the ordered source, source cursor and first $j$ emitted glyphs. The source cursor advances on a deletion. An insertion advances the output index. A replacement or copy advances both. Let $d,t,r$ denote the corresponding edge probabilities, with $r$ summing all allowable diagonal actions. Drawing a specified glyph multiplies the action probability by the learned probability of its 48-bit physical code. Copy contributes only on matching observations. The target in this numerical check is the sequence of physical codes. Matching codes and matching bitmaps agree on the selected source–target pairs. Full bitmap likelihood would also require a model of uncertainty in rendering those codes.

$$
A_{ij}=A_{i-1,j}d_{i-1,j}+A_{i,j-1}t_{i,j-1}+A_{i-1,j-1}r_{i-1,j-1}.
$$

Initialize $A_{00}=1$, omit out-of-range terms and multiply $A_{nm}$ by the terminal stop probability. With finite insertion log probabilities, a row's insertion terms can be accumulated using a prefix sum and log-cumulative-sum-exp. The implementation takes $O(nm)$ scalar work and serializes the source dimension. Counts of intermediate activations and neural edge scoring still matter for a full training budget. A recurrent state conditioned on past *edit actions* would differ between paths to the same cell, invalidating this recurrence. The check uses a prefix state conditioned on previous emitted glyph images and the pictured input, with a fixed action input. It enforces stop at the end of the source.

On three naturally occurring training pairs (equal length, expansion and contraction), exhaustive enumeration summed 88, 996 and 34 distinct paths. The row recurrence agreed in double precision to within $7.2\times10^{-15}$ in log probability. The largest absolute gradient difference was $4.1\times10^{-14}$ over the inspected action, physical drawing, recurrent and source-projection weight tensors. The calculation used inherited neural weights on CPU and made zero optimizer updates. This establishes numerical correctness for those cases. Translation quality under the new objective remains unmeasured.
