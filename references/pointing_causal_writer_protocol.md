# Reading the requested fact before emitting its glyphs

The causal Chinese writer lost the requested fact when two questions described different people on the same page. All 300 first required glyphs outside the prompt were writable, yet only 18 were chosen under correct answer history. The next writer keeps the causal body and continuous printed interface. The pictured question precedes the passage so each passage position can represent the question. At every output step a normalized mixture can write from the printed bank or return an exact bitmap from the original source. The position distribution depends on the current answer state and the contextual state of the source cell. When an entire human answer occurs in the passage, an auxiliary first-step loss teaches the position of its beginning. Identical physical outputs from different routes share probability. Copied historical forms re-enter the causal history as images.

Fit three arms from the same prior matched GPT-2 body, with the same target batches, two complete passes and the same learning rates. Compare learned pointing with uniform source positions on identical genuine questions. A third arm uses learned pointing but exchanges questions within each paired passage during training. Keep genuine single open questions the same across arms. Use two distinct human CMRC facts from each eligible training passage, rendered DuReader questions and authentic Hanziyuan forms embedded in complete pictured answers. Train up to four questions per historical plate on 512 plates. Evaluate the unchanged 571 open questions, 64 role requests, 128 CMRC question pairs, a separate set of 128 paired passages from the official traditional-Chinese DRCD test source, and 48 held-out historical families of cards in original and independently rephrased questions. Keep the first 128 eligible distinct passages by a fixed seeded shuffle for each natural paired test. Exclude long or unrenderable paired input before sampling. Preserve the previous causal and extractive controls. Score both questions on each identical passage, exact stopped answers, image overlap and source-absent writing. A change of names with the question held fixed probes role binding separately. Inspect actual returned images.

The primary test is improved exact both-question accuracy over both controls on the separate DRCD sources. Evidence for historical writing requires full captions containing the two actual requested forms in the right order. Open answer improvement requires improvement on source-absent cases independently. A gain in copying alone does not qualify as general language learning. A failed paired comparison calls for testing whether the reader identifies the wrong evidence before the writer starts. Each fit uses one 4090 D, at most 20 GiB allocated memory and 20 minutes. All earlier runs remain intact.
