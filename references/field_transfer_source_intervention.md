# Which source path changes the target distribution?

The two completed fits have almost identical development likelihoods. Measure both finished models on every disjoint equal-length pair within each of the two development works, formed in original row order. Swap the ordinary source image and the learned field separately, keeping the other path and the true target history fixed. Use both directions of each exchange. Equal length preserves the valid-position mask and avoids time warping the states. Also zero only the additional projection to test the trained causal decoder on its original source path.

Record natural-log likelihood and next-choice changes with one- and two-path replacements, and split the both-path likelihood difference equally across the two possible intervention orders. The sum equals the full change. The double difference measures order dependence of the attribution. Include every genuine glyph and stop. These conditional comparisons identify how the trained model uses each path on these cases. They cannot establish the meaning of a free reply.
