# Identical answer histories from different pictured passages

The broad translation writer reads three hundred and sixty as an age in an astronomical passage. The original book archive frequently supplies an age after 年 and a number. To measure whether a writer can use its source to choose the next word, hold the entire answer history fixed while changing the source. For each pair, the two pictured sources have different recorded next glyphs at the end of an identical target prefix. Both candidate glyphs must be absent from both source images. A source copier cannot emit either candidate, and a model using only the answer prefix must give both passages the same ranking. The latter model can win at most one of two strict choices.

The training partition yields 10,244 disjoint pairs from 55,872 actual book pairs, with members from different chapters. The common prefix has two to eight cells. The preparation code verifies both transcriptions against the original bitmap arrays. It considers longer common histories first and selects deterministic, row-disjoint pairs. This procedure identifies a set of candidates; editorial work must establish whether either branch would actually be wrong given the other source. ## Do the observed alternatives identify a linguistic choice?

We read the first twelve pairs in SHA-256 order of the string `context-fork-pilot/{pair_index}`. Only two qualified as provisional content contrasts. In one, 皆士而各著 and 皆许之 share the modern prefix 他们都, followed by 在做官 and 答应了. In another, 宣宗始遣 and 宣宗悟 share the pictured name 宣宗, followed by 开始 and 明白. The remaining cases expose several confounds. Two glosses can use 特意 and 特别 for much the same reason. Translations can supply a person's name from the surrounding chapter, or convert a cyclical date into a numbered day using information missing from the prompt. A difference in the next image alone cannot establish that either answer is wrong. [Twelve individual judgments](evidence/context_fork_editorial_pilot_20261119.json)

For the next comparison, the unit of judgment should be a complete alternative phrase. A second phrasing that preserves the same event must not count as a negative. For approved contrasts, compare the score difference between the two alternative phrases for each source, then require both strict choices and inspect each freely generated translation. Test participant roles, polarity and the referent of quantities. Reserve complete chapter and sentence families before fitting. A passing result requires more faithful free translations on the new reading sample as well as improved paired choices. This training-only inventory supplies neither a new checkpoint nor an estimate of test performance.
