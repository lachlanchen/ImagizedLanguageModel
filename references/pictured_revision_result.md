# A visual editor reads its source but still loses meaning

The editor changed **脱因，蒙古人。** into **脱因是蒙古人。**, the recorded modern gloss of a classical biographical statement. It also changed the valid date 丙辰 into 丙日. Both examples are complete, original outputs. The released CPU pipeline reproduced all 1,024 saved drafts and all 1,024 final answers byte for byte in a two-thread replay. ## Reading the classical source changes the answer

Each training example contained a pictured classical passage and a modern draft generated by a composer trained outside that passage's chapter. The reviser learned 18,102 local alternatives, including deletion, from 55,872 pairs. Two bidirectional encoders read the complete source and draft. The score for replacing a draft cell combines a training-frequency prior, the similarity of a contextual query to the ordered ink of the candidate fragment, and a learned score for making a change. The alternative action copies the original image exactly. The input must contain ordered 32 × 32 cells. The reviser can preserve unseen ink, but its new writing draws from observed training fragments of up to four images. Its answer ends with the draft. [Model and training protocol](pictured_revision_protocol.md)

We fixed the change threshold on 512 development passages before generating the fresh test answers. A complete independent recount on the emitted bitmaps reproduced each per-passage distance. The 1,024 test passages contained 23,903 reference glyphs from 623 chapters excluded from fitting, threshold selection and the preceding three cohorts.

| System | Glyph edits | Complete exact | Exact requiring a change |
|---|---:|---:|---:|
| Copy classical source | 14,141 | 13 | 0 |
| Modern first draft | 13,356 | 12 | 2 |

The model changed 189 drafts. Of these, 82 moved closer to their references, 40 moved further away and 67 kept the same distance. It gained one complete exact reference and lost two. The chapter-bootstrap interval for error reduction versus the draft was **0.088–0.326 percentage points**. Exchanging sources changed 399 output streams and increased error by **0.58–0.94 percentage points** at the paired 95% interval. The true source helps the physical decision. A single corpus gloss remains an incomplete measure of meaning. [All scores and output archive hashes](evidence/pictured_revision_20261118/summary.json)

## A paired reading of the edits

One study-involved model reader graded complete answers before the randomized method assignments were revealed. The grades distinguish faithful modern prose, partial translation, unchanged classical text and error. Numbered dates substituted for sexagenary days could not always be verified from the isolated source. Proper-name corruption and extra material in the archive also lowered some reference grades.

| Input and output | All eligible outputs, stratified by source (18) | Outputs actually changed, first per chapter (18) |

| Untouched draft | 0 | 3 |
| Revised | 0 | 1 |
| Revised with mismatched source | 0 | 1 |

Four cases overlap across packets. The two previously faithful drafts lost in the changed sample were the date 丙辰 and a report of flooding. No changed example gained full credit there. Revisions introduced five temporal errors and one grammatical error in that reading. There were no newly flagged identities or reversals of polarity in the changed packet. These counts describe the reviewed passages. They are too small for a population-wide rate. The phrase composer remains the default. ## Recognizing the glyph and interpreting the sentence

A separate control used the same local Qwen3-VL 8B Instruct Q8 model with the same instructions and text decoder. On the eighteen source-stratified passages it produced twelve faithful translations from literal text and eight from pictures alone. In a separate request it transcribed sixteen of the pictures exactly, with two edits over 294 non-whitespace characters. No translation or transcription reached the output limit. The modality-blinded reader had already seen these passages.

For **罹禁网者，人人自以为不冤。**, the model transcribed every glyph correctly. Given the literal text it referred to people receiving a legal sanction. Given the image it instead described people banning the internet. Accurate transcription in a separate request does not ensure that the translation uses the same reading. This is a pretrained multimodal baseline with a text decoder. Our independent picture writer still lacks comparable language ability. ## Resource accounting and reproduction

The editor trained 255,046 parameters for eight passes in 69.1 seconds on GPU 0, one RTX 4090 D. Peak allocated training tensors used 181.9 MiB. Preparing the four out-of-chapter draft sets previously took 79.3 seconds on CPU. The final composer and reviser occupy **6,391,309 bytes together**. That figure describes the serialized weights and tables. It excludes runtime libraries, activations, data preparation and the two comparison-only pretrained models. The Qwen3 and Qwen3-VL comparisons used separate local checkpoints and did not teach this fitted reviser. Comparisons of training efficiency require matched answer quality.
