# Retrospective real-first-state check

After the fixed full-unit transfer and complete function qualification, compare
the completed candidate and its balanced parent on all 128 previously saved
first states from the two earlier answer cohorts and four conditions. Their
existing source-policy audit identifies these states and allowed reference
initials. This is explanatory development evidence, not a third fresh cohort.
None of these states enters the registered transfer fit or calibration.

Run each state's actual continuous writer in FP32 and retain the binary image.
Measure foreground F1 at least .95 and canonical pixel equality against every
supported allowed first reference. Keep unsupported cases in the denominator.
Record the joint count of correct source-first decisions but failed physical
F1. Source decisions are reused from the prior report; no lexical matrix or
full reader is loaded here. Inspect all fixed-order reference/output boards.
No new prompt, full answer, semantic accuracy, stopping or feedback is measured.
Any failed function gate remains failed, and no checkpoint or threshold is
selected using these outcomes. It may diagnose a remedy's failure or transfer,
but cannot establish generalization or qualify a language runtime.

Use GPU0 and the existing mutex after all preceding stages exit: 48GiB host
entry, 32GiB live reserve, .5/.1 PSI, 300s pressure waiting, 600s wall cap and
6GiB allocated CUDA cap. Preserve all prior checkpoints and other projects.
