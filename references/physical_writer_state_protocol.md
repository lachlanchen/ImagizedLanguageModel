# Which Chinese expressions can the frozen decoder write?

The ordered reader recovered 39 of 256 correct expressions when given the actual training donor containing the same eight glyphs and the same recorded answer. Before another reader fit, test whether the frozen uniform writer can generate entire training expressions when supplied a suitable 192-dimensional state. Use the unweighted diverse checkpoint, whose context is bounded by tanh, and every distinct answer in its 142,878 training windows. Include targets imperfectly reproduced by its fixed renderer. Compute the average reader state for each expression from the training inputs. Score true stopped free outputs from these centroids and from optimized states. For each expression independently, start at the inverse tanh of its clipped centroid, optimize only that vector with 100 Adam steps at learning rate 0.08 on the negative physical path log likelihood including stop, and pass tanh of the vector to the unaltered recurrent writer. Keep its existing four-path beam and actual emitted-pixel feedback. Save all output pixels and optimized states and verify the normal passage and direct-state inference entry points agree on a fixed batch. Freeze all network parameters. Report whole-expression exact counts by training frequency, renderer reachability, legibility and physical path likelihood. At least 90% exact overall and in the one-to-five training-occurrence group warrants a separate reader alignment trial. Otherwise investigate where the target path is lost using these complete generations. The per-expression states use known training answers. Their scores measure control of the writer, with no claim about inferring an answer from a new passage. Use one GPU, two host threads and the same limits as the preceding experiment.
