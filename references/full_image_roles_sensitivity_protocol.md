# Locating the influence of inferred event marks

Free answer scores can remain unchanged when a conditioning channel affects only a few glyph decisions. For the final marked writer, compare the correct pictured sentence under its own predicted fields, the same fields rotated halfway through its occupied cells, and all fields zero. Use the 96 reserved book requests and all held positive/negative controlled clauses. At each supplied target prefix record the probability of the actual next reference bitmap (or stop), the winning decision, and the change in accuracy. Also count whole free-answer image changes between original and displaced fields from the existing archive. Report the fraction of every panel changed, the mean difference in reference NLL, the average field projection magnitude relative to the visual input, and role-field precision/recall. This measures the operational influence of the channel separately from linguistic correctness. Use final weights only and make no optimizer updates.
