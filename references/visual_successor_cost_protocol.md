# Cost of a visible and a character-indexed successor predictor

The same Chinese passage task permits a direct, small-scale comparison of learning from pixels and from explicit character identity. Keep the articles, candidate order, training sources, chunks, optimizer, seed, CPU limits and number of observations fixed to the [visual successor comparison](visual_successor_protocol.md). Register the character-indexed comparison before reading either trained visual result.

Replace the visual shape encoder with a learned 96-dimensional embedding for each Unicode character encountered in the 2,127 training passages. A single unknown embedding represents characters outside this repertoire. Verify the complete rendered bytes of each training passage and every test pair against the visual experiment. Keep the initial query and candidate projections identical. Use aligned supervision for one full epoch. Record training seconds, parameter counts, estimated checkpoint payload, exact observations and paired article-level accuracy differences. Include a bank of known character indices in the parameter count. Report wall time for fitting and separately for source recovery and evaluation.

This fixed-budget comparison can show which predictor learns more on this task and how long each fit takes. Quality-matched training speed requires measured time to a common quality threshold. General language efficiency additionally requires independent complete answers at a useful level and comparison against a named language model. This character-indexed control has the same small context network as the visual predictor.
