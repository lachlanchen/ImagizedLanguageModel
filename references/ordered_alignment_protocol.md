# Following source order during visual translation

The existing bilingual visual lexicon can retrieve the correct pictured source but discards source order. Test a hidden-state alignment over positions in the actual source. Each target strip draws from the previous bilingual table at its alignment position, with the same total null weight as in the unordered model. Start uniformly. Between strips, learn a mixture of uniform resampling, moving one place left, staying, moving one place right and moving two places right. Clip movements at the source ends. The uniform-resampling model recovers the unordered likelihood. Freeze emissions, printed repertoire, lexical weight (0.5), prior correction, neural model and stopping rule. Sum over alignments during training and over both alignments and compatible target strip boundaries during writing. Source-position alignment has precedents in statistical translation. [Vogel, Ney and Tillmann](https://aclanthology.org/C96-2141/)
