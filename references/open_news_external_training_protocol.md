# External news evaluation of a writer trained on human-reviewed translations

The initial 2021–2023 and TED split yielded 1,368 training sentences, including 210 unfamiliar-ink sources, and 179 held sentences, including only 28 unfamiliar sources against a fixed minimum of 30. The original comparison was withheld. Preserve its vocabulary, cases, split and receipts. Test a separately specified comparison using the same 1,368 training sentences and an entire additional year as the evaluation population. The 28 cases that prompted this decision stay outside the confirmatory cohort.

Use the official WMT 2017 Chinese-to-English news shared-task source and English reference. Read the actual document identifiers and original segment alignment. Exclude normalized source or target text seen in the 2021–2023/TED study and all WMT 2020 annotations. Remove duplicate source or target surfaces. Retain sources with 1–96 printable cells and complete English references within the fixed 96-cell training/evaluation repertoire. Use the first 96 sources in deterministic SHA-256 order within each familiar/unfamiliar group, or all if fewer. The external cohort alone must contain at least 30 in each group. Reserve its complete hashes before fitting. Report the distribution and selection boundaries. No current experimental model score may enter selection. Public data can overlap earlier foundation-model corpora. The WMT 2017 references were separately supplied for a translation shared task; they lack the individual MQM annotations used in the later training cohorts. [WMT 2017 translation task](https://www.statmt.org/wmt17/translation-task.html)

Keep the matched initialization, clean training data, eight epochs, ordinary likelihood, rehearsal, 16 GiB/30-minute ceilings and four free-writing conditions from the original protocol. Inference for the parent also uses the open source interface so unfamiliar items have an actual parent comparison. Measure all saved answers. Make no held-based selection of weights or stopping epoch. Preserve every output and both trained arms regardless of the result.
