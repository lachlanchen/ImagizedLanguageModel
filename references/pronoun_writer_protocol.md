# Restoring person annotations to a visual writer

A printed 之 in object position repeatedly received the English verb *go*. The released writer's training records contained 211 occurrences glossed *go* for that bitmap and no accepted pronominal gloss. The raw Kyoto corpus includes bracketed annotations of grammatical person which the English-word filter dropped. This intervention adds pictured canonical object glosses for the three person tags in direct object position. We render *me*, *you* and *it*. The third-person convention is an evaluation of grammatical person. Actual translations may require *him*, *her* or *them*. Those three tags supply no antecedent supervision.

Train a residual layer on the fixed writer context before its English speller. The image encoder, source selector, English motor and stopping rule remain frozen. At inference the residual receives only the visual window representation. Training uses tagged object occurrences in the six original training works plus old lexical answers, including all lexical examples of the newly supported printed headwords. The matched control exchanges all pictured answers within headword over the same batches.
