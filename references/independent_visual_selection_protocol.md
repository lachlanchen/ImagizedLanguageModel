# Choosing one pictured translation for one source image

A common background calibration improved the number of pairs with two correct independent choices in a diagnostic that used the average length of both source images. A deployable reader receives one source. Fix the background using only the length of this individual source and the target direction. For each integer source length 1–96 select the nearest 16 training sources by absolute length distance, breaking ties with the same fixed random training order. Package the bank and the numeric training-image merge ranks for independent use.

Use the frozen parent strip body to score a complete target image, including stop, at its canonical physical segmentation. Rank by the conditional log score on the actual source minus the arithmetic mean of the log scores on the 16 calibration sources. Compare raw and per-action-average scoring. Recount both independent choices on all 96 book pairs, 168 controlled reversal pairs and 84 identical-bag reversal pairs. No second test source or reference label may enter any individual choice. On free book and OPUS requests select among the three already archived autonomous candidates (parent, aligned, shuffled in this tie order). Consider stopped candidates first. Count complete source meanings using the original masked votes for the exact candidate selected and report the oracle proposal ceiling. Preserve case choices and raw answer associations. No score or beam width is fitted to these cases. This is a within-panel follow-up on models already assessed, separate from the registered book endpoint.
