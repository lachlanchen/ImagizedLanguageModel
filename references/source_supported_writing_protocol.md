# Predicting the content of a pictured translation

The previous visual strip writer assigned 164/168 agent–patient contrasts correctly with both answers supplied. During free generation it retained both named participants in 0/336 answers. This experiment asks whether an explicit source-conditioned prediction of target content changes those free answers.

Freeze the released independent strip body, its action repertoire and physical drawing motor. Fit a new multilabel predictor of the set of visual strips present in each parallel target. Its only input is the frozen visual source memory, in reading order. Score each output strip at local source positions and pool across valid positions. At each greedy writing step add a positive log probability ratio relative to training prevalence, limited to 2.4 nats. Apply each bonus up to its first emission and keep the original stop score. No target, text tokenizer, reference name list or teacher is available to the writer. Both fits use identical fresh head parameters, true targets, physical source length buckets, four epochs, batch order and optimizer schedule. The aligned arm sees its true source. The control permutes sources without fixed points within each training bucket batch where possible. Include the unchanged parent and an exchanged-source aligned writer at evaluation.

Reserve 24 new paired passages from each of four unused books before fitting. Require a strictly positive lower paired four-book bootstrap bound on the source-only two-order whole-meaning advantage over the unchanged parent, no decline in either direction and more successes than the shuffled-training and exchanged-source controls. Show the first pair of the first two works with alternating directions and the first additional candidate-only success if one exists. Retain all images and a CPU replay. Use the previous controlled 336 requests for a secondary paired diagnostic of both given names, requested predicate and extraneous names with literal spelling checks. Measure support ranks and probabilities on held targets and the search margin at correct target prefixes. Count truncated outputs and report measured compute. Four books and a model judge limit generalization. A failed complete-answer criterion leaves free writing open.

Use GPU 0 serially, up to 20 GiB allocated, two CPU math threads and at most three hours per fit. Additional projections use at most 192 hidden dimensions. Select the last epoch in each arm. Do not select a checkpoint or tune bonus strength on the held requests.
