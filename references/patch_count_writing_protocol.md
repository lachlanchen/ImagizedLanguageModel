# Learning a conditional distribution over physical ink patches

The native writer generated zero exact successor images from 1,024 contexts. Changing its decoding rule increased the difference between contexts while lowering source ink overlap. A three-glyph count model had previously distinguished some supplied alternatives. Test whether local counts can support **actual drawing** from a passage. The model outputs the 16 nonoverlapping 8-by-8 patches of a 32-by-32 glyph in reading order. It stores count tables and literal observed patch patterns. It has no stored table of complete answer glyphs, output font, OCR or lexical prediction head. It does discretize visual evidence.

The signature of an input glyph records which of its 16 patches have above-average ink mass. At each output position interpolate observed patch counts conditioned on the last two signatures, the last signature, and the unconditional position frequency. For observed counts with total N and T distinct outcomes, the shorter distribution receives weight T/(N+T). A second interpolated distribution conditions on the already generated patches above and to the left. Multiply the two distributions and divide by the unconditional position frequency, then normalize over observed physical patches. A fixed uniform escape of 1/65,536 gives all 64-bit patterns positive sampling probability. With greedy decoding, the uniform term leaves the patch ordering unchanged. Distinguish mathematical support from successful new writing. A separate smoothed continuation/end distribution learns from all genuine passage endings. Each next state reads the actual emitted pixels.
