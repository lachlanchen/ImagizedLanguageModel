# Can a small Chinese text teacher distinguish the intended insertion?

Before distilling a larger model into a visual student, test whether its judgments contain source-dependent information at the same ambiguous insertion sites. Use Qwen3 4B Q4_K_M offline. Draw 32 pairs without replacement in seeded order from the existing 6,720 calibration pairs. Require differing first reference glyphs, nonempty modern prefixes, distinct chapters within a pair, and matching insertion lengths of at least two. The calibration partition is diagnostic and cannot serve as a later student test. Inputs include the complete classical sentence with the proposed insertion boundary identified and the genuine modern prefix. Do not show the following translation, chapter title, answer key or a worked translation. Offer only the two recorded phrase alternatives.

For each recipient present the authentic and exchanged classical sources, each in both answer orders. Count a correct choice only when both orders select the recipient's recorded phrase. Report inconsistent responses, both-correct pairs, and paired changes from exchanged to authentic sources. This probes whether a text teacher already contains useful linguistic evidence. It supplies no evidence for free image generation, and legitimate alternative translations can lose exact credit. A useful pilot must achieve at least 40/64 correct under both orders and a positive lower paired bootstrap bound for the authentic-minus-exchanged difference, resampling the 32 original pairs. If it passes, test offline transfer into a visual sentence encoder with a held-out comparison on physical images. Otherwise examine the recognizability and ambiguity of the underlying phrases before allocating a larger training budget.

Score the same two candidate images under the frozen and preference visual writers, including the causal within-phrase history and the stop after the last glyph. Count a strict win only above 0.0001 nats. Each candidate uses its own previous drawings for likelihood evaluation. Neither choice ordering nor an alphabetic option label is an input to these physical likelihoods. This is a recognition measurement accompanying the free-generation test.

The first pass returned 71 responses outside the registered A/B syntax, including literal Chinese option names. Preserve that score. In a secondary response-format diagnostic accept only the complete strings 甲, 乙 or an exactly consistent Chinese label with its Latin letter in parentheses. For every remaining undecided reply, present the identical question to the same model with a JSON string grammar restricted to A and B. Freeze all earlier decoded replies, including errors. Report the additional calls, paired results and unresolved replies. This sensitivity analysis is conditional on the observed formatting failure and requires fresh material before it could support distillation.
