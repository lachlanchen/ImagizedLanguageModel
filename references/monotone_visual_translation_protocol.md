# Restore sentence alignment before fitting the pictured translation

The blinded within-chapter calibration review identified both faithful translations in only 22 of 64 deliberately confusable pairs. Many other glosses describe neighboring events. Estimate this problem separately in unselected material. Retain the old archive and all frozen results.

In each raw chapter, compare each classical sentence to nearby modern sentences in their original order. Score lexical overlap excluding punctuation, with adjacent pairs and length as supporting signals. Find a single monotone path through the chapter with skipped source/target lines allowed. Accept a substitution only for a sufficiently supported, strictly better match; retain uncertain targets as such. On fresh chapters compare old and revised glosses under blinded order. Report edited and unedited strata separately. Do not infer an archive-wide rate from the deliberately difficult roster.

Compare two image writers on the same ordered classical sources, one with the original references and one with the realigned references. Use a finite sequence of drawing positions per pictured source cell to remove recurrent phrase looping by construction. The model chooses how many positions to emit at each source cell and whether to copy its source image or draw a new one. New drawings predict successive four-pixel groups and use the existing physical renderer. Report unreachable reference lengths. Freeze the schedule, use independent chapters and generate whole answers with no modern prefix. Compare with direct source copying and report meaningful examples, original and revised reference distances and complete answers. A gain on the paired data-quality experiment alone cannot establish general language.

Use the first 32,768 shuffled training rows or all rows if fewer, and the first 2,048 independently shuffled held-out passages. Exclude chapters from the 64-case reading packet. Eight passes at batch size 96 use identical shuffled orders and initial weights, AdamW with learning rate 0.001 and gradient norm limit 1. Every source cell has up to eight emissions. Clip over-cap training blocks only for the loss and count every affected sentence before training. Greedy block length, a learned copy decision and four-way-beam within-glyph drawing produce every output without a target prefix. Use a single GPU with at most 8 GiB allocated, 6 GiB process RSS and a 24 GiB host reserve. Do not choose a checkpoint using the test set. Score completed physical output against both old and realigned references, and make a separate blinded contextual assessment of whole model outputs.
