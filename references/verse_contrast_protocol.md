# Does comparing plausible sources improve what a verse model writes?

The Tang writer often returns a common phrase even when different ink survives on the page. The next comparison continues the fixed ink-bound and byte-bound models on their original Tang training records. Both controls receive masked restoration, visible shape identification and left-to-right two-cell likelihood. The treatment also receives logistic loss on the margin between the original and exchanged assignments of two sources to two authentic endings. Negative sources have the same metre and named poet. The targets are held constant under exchange.

Use 4,000 steps of 64 examples for each of four serial fits, 8 GiB allocated and 20 minutes per fit on a single card. Fix seeds, draw orders, gap positions, source typeface and optimizer. Save the final weights. Report the energy of the parent and continuation. Reserve eight Song shards at offsets 0 through 224000 in increments of 32000 at the Tang source revision. From each, select up to 512 pairs in a seeded random order. Exclude Tang author strings, either line seen in the retained Tang partitions, repeated Song lines, and unrenderable primary glyphs. Freeze all cases before fitting. Keep unfamiliar printable test glyphs in the denominator.

The primary endpoint is an exact adjacent two-cell repair under ordered width-eight decoding. Compare against the matched continuation by resampling Song author strings. Report the width-eight search certificate, left-first greedy, confidence-first filling, whole lines, source exchange, true phrase source preference, count baseline and matched bytes. A gain in source preference alone is insufficient. Show the actual pixels of fixed cases. If the exact-repair interval includes zero, retain the previous released default and use the observed errors to select a different intervention.
