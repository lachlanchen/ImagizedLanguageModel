# Training-only preparation for global form supervision

The completed physical tree writer produces over-dense masks and no exact
targets. The next bounded change adds whole-form supervision to its actual
pre-generation condition. This stage prepares labels only; it admits no neural
call, optimizer update or language evaluation.

Use all 68,948 packed binary masks in the existing prepared training support.
Sort distinct 128-byte masks lexicographically and assign contiguous temporary
labels. Identical physical images share a label, including the empty image.
Preserve original source labels and all physical aliases. The class is a visible
form, not a Unicode identity, meaning or font-invariant concept.

Map every target in the unchanged conditional cache: the complete book's 512
positions, short question's five and longest question's 35. An unsupported image
terminates preparation; no target may be omitted, approximated or rendered.
Save class-mask hashes and all target labels, without copying context weights or
storing a class-to-image inference lookup. Report actual class count and exact
coverage. This is source preparation, not a repeated source-alias audit.

The registration binds scripts, module, tests, numerical receipt and immutable
source files before loading image arrays. It must be committed and pushed first.
Use the serial project mutex, no GPU, two CPU threads, 180 seconds, at most
2 GiB process RSS, 48 GiB entry and 24 GiB runtime host reserve with low entry
memory pressure. Preserve any failed execution. No automatic retry or full
language fit follows. A separate registration must bind a real candidate trial
to the resulting labels and unchanged completed tree control.
