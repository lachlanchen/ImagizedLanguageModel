# Learning from the glyph the visual writer actually emits

On 1,100 incorrect first images at locally matched evaluation sites, the sentence-conditioned writer gave greater probability to the recorded signature than to the emitted one only seven times. This motivates changing the learned first-image distribution. The teacher score is the sum of twelve normalized four-pixel log probabilities, with each candidate providing its own within-glyph history. All evaluation sites and ratings remain frozen.

Prepare the next comparison on the preceding 120,628 training and 6,720 calibration pairs. Collect the actual free first image of the **frozen within-glyph parent** independently at both sites of each pair. Retain correct emissions and attainable as well as unattainable references. No output identity or text enters the running visual model. Use the parent for both arms to avoid inheriting the previous residual's tendency to stop prematurely. Compare two new residuals acting only on the first drawing state. Match initialization, source passages, exposures, optimizer and calibration partition. Both learn the full first-image likelihood. At sites where the emitted signature differs, the second additionally learns a logistic preference for the reference over this exact generated rival. Subsequent drawing, physical feedback and stopping use the unchanged parent and the newly written pixels.

Evaluate both against the parent, equal-exposure likelihood arm and the expanded local count control at all enrolled passages. Report first-glyph and exact stopped phrase gains and their chapter-bootstrap intervals, multi-glyph accuracy, unseen insertions, source exchange, actual images and blinded contextual readings. This intervention seeks useful source-dependent content at the first generation step. If the writer only becomes better at demoting its previous favorite, inspect the new free choices and their ranks before expanding the training schedule. If performance on complete phrases improves, test retention when the model must find its own insertion boundaries.

The two new networks take the frozen source boundary, pooled source state and causal modern prefix state. A 256-unit GELU layer maps their concatenation to an additive 128-dimensional first-draw correction, initialized to zero. Use eight shuffled passes, seed 6811, 512 sites per batch, AdamW at 0.0006, weight decay 0.01 and gradient norm limit 2. The reference term is negative joint first-image log likelihood. The preference term is the mean softplus of the emitted log probability minus the reference log probability on different-signature examples in the batch. Choose the global correction scale from 0, 0.25, 0.5, 0.75 and 1 by exact freely decoded first bitmaps on the calibration chapters, breaking ties by reference likelihood. Only the final optimizer state enters calibration. Record inherited runtime and preparation costs separately. Use the parent and existing expanded count predictions for matched controls.
