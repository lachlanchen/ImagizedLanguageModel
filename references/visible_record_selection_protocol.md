# Locating an explicitly pictured headword before writing

Removing the distractor record recovered 820 complete dictionary answers without changing the writer. Test an inference-only locator on all five frozen dictionary prompt sets. Locate visually delimited headwords by exact physical equality to the two printed brackets. If exactly one record head occurs in the question image, give that record to the frozen matched writer. Otherwise keep the full card. Access only question and card pixels for selection. Keep the original question, model, memory, greedy generation and stop. Score against the same targets after generating. Check image-array and local-address implementations agree. Report complete answers, fallback rate, changed answers and which record was selected. Evaluate unstructured natural text separately for changes of input. This rule assumes a printed headword and known layout; it cannot resolve visually different fonts, synonyms or unmarked historical records. Keep the generic model and its failures available. One GPU 0 inference worker, 5 minutes, no parameter updates.
