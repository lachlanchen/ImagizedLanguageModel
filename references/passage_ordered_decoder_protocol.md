# Testing whether an instruction fragment creates an extra answer

The varied planner recovered the complete first and second question images on 9,571 and 9,573 of 9,600 requests with the shorter Chinese wrapper. In 8,561 cases it selected an extra contiguous reading region before two otherwise separated regions. Train no parameters. Find the maximum total learned action score over a prompt prefix, contiguous reading regions separated by a copied prompt cell, and an optional learned stop. A model can choose any number of regions, an unfinished reading, a premature stop or an empty result. Apply this same operation to singles and all wrappers. The input contains no supplied question boundary, answer count or punctuation identity. Verify the dynamic program against exhaustive enumeration on short inputs. Use the frozen varied planner and original reader. Compare every previously registered official and internal item against independent per-position decoding. Require at least 400 official pairs correct in both orders for each alternative Chinese instruction, 500 for the familiar instruction, 430 internal complete requests and 434 internal singles. Report English separately. Any remaining large error in choosing the passage content limits all general-language claims even if the rule passes. Preserve the unchanged reader on failure. Limit execution to GPU 0, 86% of device memory and 600 seconds.
