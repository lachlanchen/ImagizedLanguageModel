# Does a pictured source help complete missing words?

For each book and OPUS translation in the sealed panels, supply the surrounding target strips, their positions and the number of missing strips. Mask one contiguous quarter of each sentence, rounded up. Choose the start uniformly by a fixed hash of panel, case and language. Both writers receive exactly the same gaps. Make one parallel prediction at all missing positions. Compare the correct source image to the length-matched exchanged image used in free evaluation. Record exact missing content, average gold-strip log probability, and raw generated answers. The paired difference in log probability measures predictive use of the source under supplied target context. Residual target content and known length make this distinct from free writing. These secondary diagnostic measurements have no effect on model selection.
