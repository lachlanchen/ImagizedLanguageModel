# Complete-answer assessment after contextual adaptation

This supplement is fixed before the main fit or any adapted-model evaluation.
The final 18,000-update checkpoint is the sole candidate. No development output
chooses a checkpoint, loss weight, training duration or model width.

The component qualification in `glyph_tail_adaptation_protocol.md` remains
unchanged. It measures every training predictor and actual full-body copy
transfer, with the declared thresholds. Record its full outcome and inspect all
eight raw sample boards. A failed component gate must remain a failure.

After that review, measure all 72 complete answer streams even if a component
fails. This is an assessment of the fixed candidate, not permission to promote
it as usable. In particular, a copy-retention failure should not prevent the
language assay from revealing whether adaptation helped question answering.
Record the physical-gate flag alongside the complete-answer report; do not
silently waive or lower its threshold. All malformed outputs and caps count.

The fixed streams are eight original training controls, sixteen original normal
questions, their sixteen question-erased controls, and 32 reserved paired
questions. The first forty are explicitly reused. The new 32 were selected by
context/ID hashes, without answer coverage or model-result selection, as sixteen
contexts with two questions each. Their complete input images were actually
viewed before the main fit. Their source pretraining exposure is unknown, and
this is not an exhaustive decontamination claim across every older experiment.

Generation accepts input images and weights only; no reference string, source
head, tokenizer, font, canonical glyph inventory or teacher may choose or repair
an answer. The cap is 64 complete 32×32 glyphs, with learned stopping, and actual
emitted images are re-encoded for every continuation. Preserve each raw tensor,
PNG, stop probability, contextual state and image-feedback hash. Inspect all
72 streams before opening the current reference strings for scoring. Record a
complete transcription or explicit uncertainty for each stream. Later canonical
comparison is evaluator-only; do not snap output to the nearest font glyph.

The pilot criterion is at least 24/32 clear, naturally stopped complete reference
matches on the reserved questions, with both questions correct in at least
10/16 contexts. This is a prospective task-specific target, not a general LLM
parity threshold. Report strict canonical pixel matches separately. Review is
agent-based unless an independent human actually grades it. Unsupported reference
forms, alternate wording and ambiguous strokes remain explicit; they are not
removed to improve the denominator. Report old normal/erased controls and
training controls as well. Passing a copy gate, gradient preflight or pilot
criterion alone does not complete the broad independent-ILM objective.

An evaluation-only amendment, recorded while the main fit is running and before
any new answer is generated, binds the evaluator source hash at raw-output
review and checks it again before reference scoring. It also reports all sixteen
fresh context pairs, marking which have disjoint allowed reference strings and
which produce two distinct, correct complete image answers. This descriptive
question-discrimination check does not filter the cohort or change the pilot
criterion. Equal answers to two questions with overlapping references are not
by themselves evidence that the model used the question. The paired readout
control's complete output review is still required before either score.

Before either final candidate produces any answer, the separate
`glyph_reader_execution_protocol.md` fixes a shared resource-wait amendment
and per-answer timing boundaries. Timing never changes which answers count,
the fixed cohort or the correctness thresholds. Failed and capped streams
remain in the total generation wall time.

Assessment binds the source files used to map every stream to its question.
Scoring authenticates those mappings and the registered training/development
reference-file hashes after output review and before opening reference strings.
The paired archive must retain both conditions together: all 144 output PNGs,
52 actually viewed boards and every qualification glyph. Pixel F1 and exact
flags are recomputed from saved qualification pixels. Publishing one favourable
condition or omitting caps is not an accepted result package.
