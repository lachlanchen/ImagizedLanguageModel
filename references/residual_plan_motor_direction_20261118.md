# Qualify the joint physical motor before another language fit

The best completed hard-plan base still misses detail: validation F1 .943690071,
macro F1 .928693592 and three exact forms out of 952. Its continuous counterpart
reaches .996423850. The equal-bit scalar follow-up is interrupted, and its
completed continuous control misses the fixed .98 ceiling. Neither an unchanged
retry nor another bit-width search is selected.

The existing visual-plan proposal contains a physical correction distribution
that has not been trained. The next bounded change tests that component as a
**composite drawing motor**, keeping the actual final spatial-256 codec frozen.
This does not retrospectively qualify its failed base decoder. The admission
unit changes from the deterministic base D(B) to the actual joint motor
D(B) XOR R; every original absolute fidelity, exactness, empty-image and total
event condition must still be met before any contextual language fit.

For a fixed plan B, form the condition C from its signed bits and the signed
pixels of its frozen decoded base D(B). This image is a deterministic function
of B, adding explicit pixel-coordinate features without new information. Model

    R ~ P_psi(R | B, D(B));    Y = D(B) XOR R.

Use the already implemented normalized occupancy tree for R, with two
128-wide layers and four heads. Its root chooses empty/nonempty and its later
physical masks determine their own topology. No desired topology, future
target, Unicode label or glyph bank enters generation. Initialize root weights
to zero and root bias to [0,-2]. Greedy initial output then equals the saved
base for every plan; nonempty correction retains nonzero probability and a
learning signal. All other weights use a fixed fresh seed. This is an identity
residual initialization, not a trained repair or a semantic prior.

Because XOR is bijective for each B, this is exact normalized conditional image
likelihood given B. It remains different from the marginal language likelihood
sum_B P(B|H)P(Y|B). Supplied-image plans E(Y) are allowed only for physical motor
supervision. The eventual language model must generate B from earlier visible
context, produce the correction, feed its actual emitted image back into its
history and learn stopping. A corrected supplied-image motor proves none of
those contextual capabilities.

This differs from the completed direct occupancy fit: that fit generates an
entire glyph from imperfect linguistic conditions. This comparison repairs the
measured sparse residual of a supplied plan and a frozen base. The added base
image is available at deployment from generated B, rather than a temporary
classifier whose decision is discarded. It also differs from earlier bounded
DCT/flow residuals: the correction is a normalized distribution over all binary
images, not regression of an uncertain field. This is an established latent-
variable/lossless-residual construction, not a new mathematical theorem.

Before fitting, bind the exact frozen spatial-256 checkpoint, saved plans/base
