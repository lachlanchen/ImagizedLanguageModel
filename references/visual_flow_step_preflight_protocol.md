# Registered native flow-learning step

This preflight exercises the actual candidate codec, a differentiated native
flow-matching update and autonomous image generation. It is a feasibility
check before a longer learning experiment. One optimizer update cannot
establish language learning or reliable writing.

## Admission and source

Wait for the exact owner of the complete visual-semantic native preflight,
identified by PID, command and start ticks. That job must exit after all
twelve actual generations, with exact native/compiled/vocabulary-removal
replays and its ten complete original answer pages. A source/import/memory
failure does not admit the learning test. The earlier FLUX QA experiment is
therefore also preserved. Use GPU0 and the exclusive project model lock;
leave GPU1 and other projects unchanged. Preserve failures without automatic
quality retries or smaller-image fallbacks.

Reuse the complete pinned source release and compiled fixed task. Remove
the unused lexical table, word head and tokenizer as in the verified replay.
The pretrained visual/language body and image codec remain frozen. This is
adaptation of an existing model; its pretraining and full parameter count
must be disclosed.

## Trainable path

Attach rank-16 low-rank branches to the image generator's selected native
linear projections and to all connector linear layers. Each branch is
\(BAx\), with frozen native \(W\), Kaiming-initialized \(A\), zero \(B\), and
scale one. FP32 master parameters are cast to the native output dtype for
multiplication, so the source's non-autocast sampler also works. Do not add
adapters to the reader, codec, query vectors or fixed condition.

The CPU preparation constructs the actual native generator/connector graph
on the meta device, records every selected layer and parameter count, and
checks the source's activation-checkpointing support. It also loads two real
published projection weights, requiring exact zero-adapter output, finite
nonzero adapter gradients, changed adapter parameters and unchanged frozen
weights in numerical layer checks. These are projection checks, not a full
model or language result.

## Actual GPU sequence

Load the source once, install the compiled condition and remove lexical
modules. Attach the same rank-16 branches. Generate the original first
registered native QA case using its input, seed, 50 steps and guidance 4.
The exact pre-reader fields, real decoded tensor and PNG pixels must match
the earlier vocabulary-removed baseline. Stop if zero adapters alter the
actual native output.

Reconstruct four fixed training answer canvases: the first complete QA pair
and the first Chinese and English copying cases. For each target, decode
both its codec posterior mode and one fixed-seed posterior sample, using the
native shift/scaling and pixel-conversion formulas. Save all eight original
reconstructions and decoder tensors. Report foreground-pixel F1 and ink mass
against the actual target pixels. These diagnostics do not constitute OCR,
semantic correctness or qualification of the entire corpus; inspect the raw
glyphs before selecting a longer training design.

Train on the first QA case once. Derive the complete image features and
reference latents from the input page only, through the frozen native reader.
After that computation, load the target image for supervision. The trainable
connector maps the frozen features to the image generator's conditions; the
positive fixed-task branch supplies this one-example loss. Use a fresh
native training scheduler and the already checked unweighted velocity loss.
No answer string, varying text condition, OCR objective, target-dependent
crop or target image is used as a reference-image condition.

Use AdamW at 5e-5, betas (0.9, 0.95), weight decay 0.05 and gradient clipping
at norm 1. Enable native non-reentrant activation checkpointing on the
generator and connector. Require a finite loss, finite nonzero gradients in
both trainable components, at least one changed adapter tensor and unchanged
version counters for every frozen parameter. Save the real noisy target,
target/predicted velocities, input reference latents, exact noise/timestep
metadata, adapter checkpoint and optimizer state. Record actual step time
and peak GPU allocation. A module graph or numerical loss check cannot stand
in for this actual forward/backward/update.

Finally, generate a fresh autonomous answer image from the original input
and seed, after the update. No target is passed to generation. Save its real
decoded tensor and native PNG. Preserve both before/after pages regardless
of whether they differ or improve. Do not reroll noise or increase the step
count in search of a visible change.

## Interpretation

Complete execution would demonstrate native zero-adapter equivalence,
sampled codec behavior and single-update feasibility on one RTX4090. It
would not establish language learning, generalization or efficiency against
a conventional LLM. Review the original codec and answer pages, then run a
complete paired learning experiment and independent-noise held-out
assessment. The full project goal and its existing criteria remain intact.
