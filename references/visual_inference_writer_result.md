# A picture of the premise helps complete a Chinese claim

A visual writer trained on 33,441 original Chinese premise–claim pairs learned to use a supplied passage to recover missing text. On 2,947 official development examples it wrote 524 missing phrases exactly, compared with 133 when training reassigned the passages. Its decisions about whether a claim followed from its premise improved by a smaller margin. We evaluated exact stopped answer images, erased each input, compared a local text LLM and tested whether the same passage could support different answers. [Figure 83](../publication/ilm-nature/figures/Figure_83_visual_inference_writer.png) · [Hu et al., original OCNLI data and study](https://aclanthology.org/2020.findings-emnlp.314/)

| Calibrated neural and neighbor proposals | — | — | 651 | 170 |

The visual writer generated one of three complete relation sentences. On official data the 3.26-point gain from matched supervision had a premise-bootstrap 95% interval of 1.41–5.08 points. On internal validation the gain was 4.06 points (2.41–5.72). Both improvements exceeded zero against the reassigned and erased-premise controls, satisfying that limited decision criterion. The simple linear baseline also found considerable label information in the claim alone (1,647/2,947); adding the premise increased this to 1,689. With its premise erased the trained writer often failed to emit any valid relation sentence. The stronger matched-versus-reassigned comparison preserves real passage inputs. [Neural outputs and effects](evidence/visual_inference_writer_20261119/result.json) · [Physical feature baselines](evidence/visual_inference_writer_20261119/baseline.json)

Each claim in the writing task has one mask covering one to three original glyphs. The matched writer recovered 328/957 one-glyph, 130/1,013 two-glyph and 66/977 three-glyph spans. Its strongest ability was using text visible in the premise (479/880 exact when the intact target was there). It recovered only 31/1,858 if at least one missing glyph was unavailable in the two inputs. Among 1,027 cases with every target glyph absent, it exactly restored 26 spans, covering ten distinct answers. The original wording is a strict reference and another completion can be linguistically plausible. [Independent image reconstruction and visibility audit](evidence/visual_inference_writer_20261119/audit.json)

A 15-coefficient selector learned on the internal validation data chooses between the neural output and a span estimated from counts of the visually adjacent glyphs. It accepts the two pictured inputs and the proposals at inference. It recovered 651 official phrases, 127 above the neural writer (paired gain 4.31 points, 95% interval 3.29–5.34) and 257 above counting alone (8.72 points, interval 7.47–9.99). Among absent-ink cases the combined writer increased the count to 170, while counting alone retained 196. The combination produced 63 exact three-glyph spans, three fewer than the neural writer. Its deployed table and gate use 2,308,158 additional bytes. All 2,947 official outputs were independently reproduced through the inference selector from the original saved neural proposals. [Follow-up protocol](visual_span_backoff_protocol.md) · [Calibration and complete results](evidence/visual_inference_writer_20261119/backoff.json) · [Runtime recount](evidence/visual_inference_writer_20261119/backoff_audit.json)

On 12 newly constructed situations, changing only the arrangement of two subjects reversed the warranted answer. For missing writing the model completed both passage orders on 9/24 contrasts (zero with reassigned training). For relation decisions it completed both on 0/48, with identical decisions on 46 pairs. In normal CPU use changing 水 to 茶 in the visible passage changed the single missing glyph correctly. The same held for 门 and 窗. Typed text and PNG inputs produced byte-identical images for all six fixed demonstrations, including a wrong inference about an empty box. [Controlled switches](evidence/visual_inference_writer_20261119/role_switch.json) · [Normal command results](evidence/visual_inference_writer_20261119/cli.json)

On the same 105 official cases covering all 35 complete premise triples, local Qwen3-8B Q8 wrote 73 correct relation sentences versus 59 for the visual writer. The visual model's paired difference was −13.3 points (95% interval −25.7 to −1.0). Qwen reconstructed 18 missing phrases, the neural writer 23 and the combined writer 26. The combined writer's 7.6-point difference had an interval from −1.9 to 18.1. Qwen received the original text, an explicit answer format and zero task examples; the visual writer had direct task training. Both decoded freely. The comparison does not establish general Qwen parity, a training-cost ratio, or superiority in ambiguous completions. [Matched text-LLM comparison](evidence/visual_inference_writer_20261119/qwen_comparison.json)

Each visual arm used 4,184 updates and 267,528 presentations of each task. After inherited training the matched and reassigned fits took 174.2 and 178.4 seconds on one RTX 4090 D. The model has 694,152 neural parameters and a fixed bank of 7,715 writing shapes. The reassigned control retained the three records of an unlabelled singleton genre each epoch after its initial construction stopped before any control update. The other 33,438 premises changed. The matched model retained 48/96 independent English dictionary answers and 5/96 Chinese ones, and its ordinary DRCD both-correct pairs fell to zero. It gave no exact DuReader responses among 571. Only the separate experimental checkpoint received this adaptation. ## Run the writer

From the repository root, the calibrated missing-phrase command uses the locally fitted model and empirical visual table. The single square marks a gap of unknown length.

```bash
python -m scripts.restore_visual_phrase \
  --premise-text '她端起杯子，喝了一口茶。' --claim-text '她喝了一口□。' \
  --output /tmp/ilm-tea
```

Open the resulting `answer.png`. The same command accepts `--premise-image` and `--claim-image` with 32-by-32 glyph grids, including the previously saved claim PNG. Use `--premise-cells` and `--claim-cells` for wrapped grids with trailing padding. For relation judgments or neural-only restoration, use `python -m scripts.ask_visual_inference --mode decide` or `--mode restore` with the same input options. These commands need the local fitted artifacts under `artifacts/visual_inference_writer_v1/` and the inherited writing memory. The model weights and research corpus remain local.

To reproduce the two neural fits from the registered prepared corpus and parent checkpoint into a new directory, run `CUDA_VISIBLE_DEVICES=0 python -m scripts.fit_visual_inference --output /path/to/new-run`. The original data are available from the OCNLI authors under CC BY-NC 2.0. The input preparation verifies the upstream Git blobs and image reconstruction before the training split is frozen.
