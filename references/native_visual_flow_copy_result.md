# Copying remains unreliable after native visual-flow training

The final checkpoint reproduces 2 of 32 seen strings and 3 of 32 held-out
strings under the unchanged OCR exact-match rule. This completed copying
cohort tests basic writing fidelity. Its random character and word sequences
do not test sentence understanding, grammar or meaningful question answering.
The initial/source comparison is still running, so these counts do not
establish a training gain or identify the cause of failure.

| Copying task | Seen outputs | Held-out outputs | Seen clean references | Held-out clean references |
| --- | ---: | ---: | ---: | ---: |
| Chinese strings | 2/16 | 2/16 | 14/16 | 14/16 |
| English word sequences | 0/16 | 1/16 | 13/16 | 15/16 |
| Combined | 2/32 | 3/32 | 27/32 | 29/32 |

All 64 original inputs, generated answers and white-padded references are
retained in the [complete evidence](evidence/native_visual_flow_final_copy/report.json).
Every generated PNG authenticates against the actual saved decoder tensor.
The offline audit checks the original case order, input hashes, seeds, final
adapter export, native 50-step guidance-4 sampler, source code and owning OCR
calibration. No new image or neural-model output is generated by the audit.
All inputs and answers remain full 1024-square pages; reference writing is
padded from its original answer strip without rescaling.

All 64 output pages were visually inspected across sixteen original-resolution
contact sheets. The [inspection record](evidence/native_visual_flow_final_copy/raw_inspection.json)
binds observations to individual image hashes. Some strings contain clear
characters or words. Others omit characters, merge adjacent forms, deform
strokes or add punctuation. No complete manual transcription, manual accuracy
score or OCR correction is assigned. The reviewer had access to source keys,
references and OCR, so this is not an independent blinded assessment. The
clean-reference counts show that OCR is also imperfect.

The copying data consist of deterministic synthetic strings from a fixed
Chinese character inventory and English word list, rendered with the same
source font. Held-out strings differ from optimizer examples but share the
writing system, vocabulary and prompt template. These development cases have
been reused across experiments. They supply no evidence of generalization to
new fonts, historical scripts or long documents. See the
[source attribution](evidence/native_visual_flow_final_copy/SOURCE_ATTRIBUTION.md).

The [complete assessment](native_visual_flow_assessment_protocol.md) retains
its original initial/final, question-erased, passage-erased and copying
comparisons. The final normal-question result is separately
[reported with all original pages](native_visual_flow_normal_result.md).
The registered field and positive-branch sampling diagnostics remain pending.
The current checkpoint has not demonstrated useful language learning from
glyphs, and the copying result does not justify a general ILM claim.

Reproduce this bounded audit after recording actual raw inspection:

```bash
CUDA_VISIBLE_DEVICES='' PYTHONPATH=. python scripts/audit_native_flow_copy_cohort.py \
  --assessment artifacts/native_visual_flow_assessment_v1 \
  --review artifacts/native_flow_final_copy_review_v1 \
  --output artifacts/native_flow_final_copy_audit_reproduction
```

Use the existing model Python and a fresh output directory. The tool loads
saved tensors on CPU for authentication, without loading generator weights
or initializing CUDA. It refuses incomplete or changed bindings and does
not replace the frozen full-assessment program.
