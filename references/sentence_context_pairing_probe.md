# Does the pictured question change the relative likelihood of two complete answers?

For each reserved natural pair, fix the page and one physically selected fact for both questions. Score both full human references, including stop, under both pictured questions. Use the first registered reference for each, mean log likelihood per glyph, and both possible fixed fact choices with equal weight. A difference of the two within-question preferences cancels any answer-specific score that is constant across the questions. Positive values favor the human assignment. Repeat after reversing the glyph order of each question while preserving its glyph multiset and keeping the original factual strips fixed. A duplicate-question control must tie to numerical precision. Report all 96 pairs per language, complete autonomous pair accuracy separately, sign ties at one part per million, and the intact versus reversed difference. This probe measures conditional preference among human-supplied alternatives. Lexical overlap can support the assignment without grammatical comprehension.
