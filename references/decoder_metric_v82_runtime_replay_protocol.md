# Direct final-checkpoint runtime replay

Specified before the V82 matched-loss experiment completes. This is an
execution test, not a new language-quality or training-fit gate. Only after
the single current GPU job and its CPU verifier finish may a restored-model
GPU invocation run. Preserve both matched arms and every original decision.

Use the fixed original cohort case 00 and its original owning prompt pixels,
without selection by answer quality. Independently prepare the same PNG for
the CLI and check that its signed physical tensor equals the original prompt.
Use the completed metric-arm checkpoint, original seed 20267420, 32 flow
steps, 0.5 learned stop and 128-block cap. No target or answer length enters
the actor call. Garbage or empty answers must still replay as they were.

The new loader uses only its completed checkpoint and the shared frozen
foundation, codec and numeric controls. It must not open ancestor checkpoint
files, training datasets, answer caches or a teacher service. Observe file
and network accesses during the standalone invocation where available;
retain private raw traces and publish only the relevant asset-access summary.
Ordinary code, library, font/cache and GPU-driver accesses are not teacher
calls. Do not duplicate model weights or alter another project's service.

Compare emitted image tensors, every stop probability, actual-pixel feedback
hashes, stop/cap events and reader-memory identity with the saved metric-arm
case00 generation. Additional API provenance fields need not equal the
training orchestration dictionary. Verify the output PNG against raw bits and
the invoked checkpoint hash. CPU verification remains separate from the actor.
Report any failure without repairing outputs or weakening equality criteria.

Typed, UTF-8-file, image and mixed input preparation already has separate CPU
receipts. Do not call that a complete GPU replay of all four routes. Even a
passing exact checkpoint replay establishes reproducible execution, not
correct answers, general language, historical-script capability or efficiency
parity. The general ILM goal remains unachieved unless broader direct evidence
later establishes it.
