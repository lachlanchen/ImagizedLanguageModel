# Learn to recover after emitting the wrong glyph

The causal visual writer reproduces 8,840 of 22,655 next bitmaps with the recorded history. At the first genuine erroneous emitted image, keeping the later task and source fixed, the following glyph agrees with the reference in 133 of 1,019 cases versus 442 with clean history. The intact writer also fails many first choices. Both effects require measurement.

Generate the parent writer's single-step image under clean training histories at all 1,762,187 target positions. Store physical image identities, including any image outside the existing bank. Exclude early end decisions from image substitutions. Continue two identical copies of the trained parent on the same training rows, shuffled batch order, optimizer and four further passes. Use a fresh AdamW optimizer, learning rate 0.0005 and gradient norm one. The control retains the clean preceding image at every position. The recovery arm replaces an independently sampled third of eligible erroneous images with the frozen parent's own predicted image. Retain the complete clean source and supervision targets. Report the actual number of replacements. No teacher or supplied target can participate at inference.

On a third 1,024-row test, exclude all training chapters, both previous new test chapter rosters, aligned evaluation chapters and the 64-case reading. Keep the preceding length and chapter cap rules with a new hash. Compare original parent, equal-time clean continuation, recovery writer, literal source copying, and the fixed phrase composer. Measure exact changed glosses, stopping, distance with chapter resampling and a blinded reading of 18 distinct passages using the same three source-marker strata. Claim improvement in free writing only for better physical distance and stronger contextual acceptance over the clean control. Retain the phrase baseline unless the same evidence favors deployment. Preserve one recovered and one persistent failure in original pixels. Limit fitting to a single 4090 D, 10 GiB allocated device memory and 24 GiB host reserve.
