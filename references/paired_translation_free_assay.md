# Does the writer preserve a source edit in its two freely written answers?

Assess all 512 archived outputs of the independent broad writer, four per reserved family. Use the original Qwen assessor, each source in isolation, both candidate orders, and the same two boolean decisions. Replace the two corpus translations with the writer's own two stopped outputs for that direction. Each source must accept its own answer and reject the answer emitted after the edit, twice. A complete family must do so in both languages. Also count individual meanings accepted in both orders, irrespective of the other answer. Report each outcome for the full audit, the corpus-derived subset, and the constructed subset identified by byte-level provenance. A translation may be a valid paraphrase. Exact ink identity supplies an additional measure. This post hoc measurement uses already trained sources and a single automated assessor.
