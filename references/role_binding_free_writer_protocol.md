# Can an autoregressive writer express the fact in another order?

The separately scored reader supplies useful subject, relation and object predictions on the natural questions. Its exact frame writer can produce only one sentence pattern per relation. Test a separate pretrained visual causal writer with the same measured fields. Train on source-disjoint records from the same corpus, giving two word orders for each triple and a third supervision source of complete short clauses taken directly from original training passages. Some such clauses add information beyond the triple. Treat this as auxiliary supervision and measure its size. At inference give only the predicted pictured fields and an instruction indicating whether to lead with the subject or object. No complete target, inflection code or frame table may be consulted by the decoder. Compare real field predictions with reference fields and the unchanged starting writer. Count completed, stopped answers under both order instructions on the same source and against fixed physical targets. Record actual pixel sequences, including wrong strings, for all 1,280 inputs. Matched success in both orders tests generation from a bounded set of relations. Freely supported discourse and arbitrary linguistic competence require further evidence.
