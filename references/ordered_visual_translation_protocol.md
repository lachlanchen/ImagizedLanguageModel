# Translation across scripts from ordered glyph images

The independent page writer reproduced one human answer per 64 new questions in each language. Classical-to-modern Chinese tests often allowed partial copying. Translation between English and modern Mandarin requires the output to preserve the source meaning while changing the writing system. Fit a new encoder–decoder on human Tatoeba translation pairs in both directions. Keep prior models available.

Compare one ordered four-cell visual window per source position with the same window taken every fourth position. All trainable tensors, target likelihoods, seeds, training examples, batches and optimizer budgets match. Source and generated history consist of glyph pixels. Target-language selection is an explicit interface control. The target image palette is learned from training examples. Reserve connected components sharing either normalized sentence, including simplified/traditional equivalents, before fitting. Restrict the initial consumer-GPU experiment to 96 cells per side. Report exclusions, unseen target shapes and source attribution. Draw full answers up to 128 cells. Use 12 matched passes per arm, save restartable checkpoints, select the lowest development visual cross entropy per arm and score held families once. Bound each arm to 18 GiB CUDA allocation and three hours. Use one project-owned GPU serially and keep the second card available to its existing users.

Measure actual valid attention positions, GPU time and energy independently of quality. Compare outputs in both directions with chrF, exact match allowing alternative translations, stopped rate, a source-exchange control and a local 8B Q4 text model on the same fixed subset. Grade that subset for preserved meaning in shuffled and reversed orders with human and unrelated controls. Hash-select a fixed cohort before producing any replies. Uncertain statements, names, amounts or negation must survive translation. Treat speed gains as useful only with an explicit quality comparison. If packing hurts translation, retain the finer model or revise the compression. If both trail the quantized baseline, retain the translator as a specialist and keep general-language parity open.
