# Does the source help select a missing phrase?

Summed-prefix decoding removes runaway insertions but gives zero complete changed translations in both cohorts. Test where the language signal resides using the final frozen weights. In each fresh cohort pair different chapters with naturally inserted phrases of equal length (one to four glyphs). Require the same immediate preceding and following modern reference glyphs, distinct phrases, and both phrases to contain only glyphs absent from both classical sources. Use original row and phrase order, at most one occurrence per sentence, no reused sentence. Insert the other phrase while preserving all remaining modern reference glyphs. Score both whole targets with the exact alignment marginal under (1) the true source and (2) its glyphs in reverse order. Both settings retain prompt, glyph multiset, target length and the surrounding supplied reference. Assess joint source–phrase assignment and paired loss of preference under reversal by cohort. This distinguishes sensitivity of the phrase preference to source order from simple effects of phrase frequency. A fitted target preference can still arise from conventions of translation or surrounding text. Report the number of multi-glyph pairs and every unfiltered failure. No new optimizer steps.

A follow-up uses the identical frozen pairs to test whether the preference requires reading the rest of the recorded modern answer. At the final glyph of the exchanged phrase, sum the cursor mass immediately after emission. No later reference glyph, deletion or stop is required. The common target prefix preceding the phrase cancels within each comparison. Score both true and reversed sources. Check that extending the cursor calculation through trailing deletions and termination reproduces the full-target likelihood of each tested prefix. Report pair assignments and the paired order effect with the suffix withheld.
