# Writing a second line on an image canvas

The classical book writer retained some passage information but often repeated its first mistaken phrase. Test whether a writer that chooses the most certain missing cell first can make better use of the entire line. Compare this decoding order with left-to-right filling using identical weights. Also compare same-position paired-glyph counts and a matched byte-input denoiser. Fit from scratch on the 58 Tang poetry shards of chinese-poetry at b8594f81a89752241442f2ce267d6f66f96704ee. Use punctuation-delimited pairs of five or seven Han characters. Partition by the SHA-256 hash of the supplied author string modulo 20, reserving bucket 0 for test and 1 for development. Remove held pairs if either line occurs on either side of a fitting pair, and deduplicate exact pairs. Report dependence on attribution strings and novelty separately from semantic quality.

Read 32-pixel cells. Return canonical physical output shapes observed during fitting. Source images use Noto Sans or Noto Serif, with a third face (Droid Sans Fallback) confined to evaluation. The writer observes the first line and any visible parts of the second, using bidirectional attention. Train each arm on the same 10,000 batches of 96 line pairs, up to 20 minutes and 8 GiB of GPU allocation per arm. A quarter of training cases have the whole second line hidden, and the rest hide a uniformly chosen positive number of positions. Score only missing cells. Output length follows the supplied metrical form.

Use up to 4,096 test pairs chosen by a content-independent seeded permutation of the eligible rows. Evaluate a completely blank second line and two adjacent hidden cells amid genuine reference ink. Show the first test examples and genuine failures. Measure character accuracy, complete hidden spans, repeated outputs, normalized carrier length, generated lines occurring in fitting, and original versus length-matched exchanged sources. Compare confidence-first and left-first with paired author-bootstrap uncertainty and put literal restoration, conditioned preference and convincing poetic language on separate evidentiary grounds. Add the book assignment diagnostic and real verse images to the paper. If choosing the next cell by confidence fails to improve full-line glyph accuracy, retain the comparison and use its failures to guide the next learning objective.
