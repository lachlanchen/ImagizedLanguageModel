# Does the source still determine which passage fits?

A stronger editor can recover some meanings when it receives the pictured source, but a second input could also dominate a weak writer. Test the actual trained editor's conditional likelihood on adjacent held passages within each book, using each pair exactly once per direction. Compute the sum of the two true log likelihoods, including every target glyph and stop, minus the sum under exchange of complete target sequences. Each assignment contains exactly the same source and target sentences. Compare correct source-linked drafts, masked drafts, an identical unrelated draft for both sources, and an identical unrelated source for both true drafts. Test the same contrasts for pairs of prompted events differing only in agent/patient at fixed polarity. Publish strict positive counts, negative counts and ties, together with all four component scores. This conditional diagnostic uses the reference only as a scored hypothesis. It gives no credit for free writing.
