# Associative recall of the next written glyph

The broad writer reached six exact translations in 960 unseen book directions. Its ordinary next-glyph likelihood deteriorated when we increased the influence of source-specific scores. Test adding observations of what actually followed similar visual contexts. The source and generated history must suffice to retrieve a memory. The model has no access to evaluation references at inference.

Index only the 28,342 real training pairs from the broad fit. For each direction, record the normalized pooled source representation and the normalized decoder state before each true next bitmap or stop. At a new pictured source retrieve 32 nearby source passages by cosine similarity. At each emitted glyph retrieve 16 nearest decoder states from the union of these passages. The memory probability of a next glyph is the sum of Gibbs weights exp(similarity / temperature) for neighbors with that observed next glyph. Interpolate with the broad writer's distribution, including stop. This energy representation implements normalized content-addressable recall. A fixed control reassigns next-glyph values across training positions within direction and preceding glyph, preserving all such bigram counts while destroying the individual context-to-next-glyph association.

Use the same 480 development directions as for the preceding calibration. Choose a single global temperature (0.02, 0.05 or 0.1) and mixing weight (0, 0.1, 0.25, 0.5 or 0.75) by minimum summed next-glyph negative log likelihood, breaking ties in favour of the smallest mixing weight. Apply the selected strength and temperature to the shuffled control as well. If the development optimum is zero, preserve the ordinary writer and report only a fixed 0.25, 0.05 exploratory diagnostic as a separate condition. Store the data volume, build cost, native-weight provenance and both sets of control scores. Count all emitted images and roles as in the library trial. Reserve the next disjoint 96 directions for meaning: translations in both directions of pairs 25–36 in each held work. Report both graders, the failed conditions and representative raw images from actual checkpoints. To promote the memory require positive paired lower bounds against both baseline and shuffled labels on the source-only reading, positive gains on the reference-informed reading, and at least 110 intact role families. Deployment costs must include the external memory.

This adapts the existing nearest-neighbor translation principle to a writer whose input, autoregressive history and retrieved labels are physical bitmaps. Selecting a subset by source first limits the number of context comparisons. Similarity-based recall and temperature have an exact Boltzmann form. A useful contribution would be a measured transfer gain on images at an accountable cost.
