# Can a writer recover a whole answer from a blank image strip?

The list-trained writer scored zero exact on 407 difficult conversational questions. Its copy search included a matching reference for only 1/239 turns whose normalized answer words could be assembled. Test whether learning to fill multiple missing answer images, including a fully blank strip, helps the model propose complete replies. Conditional masked prediction supplies the learning objective. This experiment uses physical word patches from the pictured inputs and a learned glyph speller. [Previous results](compose_dialogue_result.md) · [Mask-Predict](https://aclanthology.org/D19-1633/) · [Masked language diffusion](https://arxiv.org/abs/2502.09992)

Reserve the next 200 eligible CoQA stories in the previously published hash ordering after the first 200. Use the identical canonical overlap exclusions, hash and input geometry, and publish source identifiers and turn counts before fitting. Use one human reference per turn. Preserve the previous 407 cases and all upstream models. Start both methods from the released list-trained checkpoint for their representation. Compare a masked writer with an ordinary causal continuation for each of the image and byte readers. Sample identical batches of 32 for 3,200 AdamW updates, learning rate 0.0002 and seed 617243. Each batch contains 16 ordinary uniform dialogue draws, eight absent-phrase copy-assembly draws, four missing-word dialogue draws and four multi-span list draws. Use all weights at the final update, with no development selection. Run serially on GPU 0; allow 20 minutes and 12 GiB allocated per fit. Account for the inherited list training and record new preparation, fit and evaluation costs.

Predict the answer length from the input alone. During training half the strips are fully masked in expectation; the other strips have a random fraction of word images hidden, with at least one hidden word. At each missing location learn to point to an observed image or spell letters, retaining endpoint supervision. Each slot receives its position, length, bidirectional answer context and pictured source. At inference choose the predicted length and start blank. In four passes fill the most confident remaining positions, feeding written pixels into the next pass. Score only completed spellings and answers. Additionally generate up to 32 proposals from the top eight lengths under four fixed fill orders (confidence, left, right and centre). Measure the presence of the single normalized reference and keep the first representative success and failure in source order. Default generation uses confidence order and predicted length. Assess the earlier copy-only beam on the same new copy-assemblable questions.

Report stopped exactness, word F1 and independent question/history and passage exchanges on all new turns and on the difficult subset. Count a source-sensitive exact only if the original matches and both exchanges lose credit. Compare against the frozen list parent and matched causal fits. A transfer gain requires more source-sensitive difficult exact replies than both visual controls and a positive lower bound for the paired story-bootstrap difficult F1 difference against the matched causal fit. Separately report top-32 coverage and predicted-length accuracy. If proposal coverage fails, measure the contributions of spelling/locating words and length under supplied lengths on the fixed cases before changing the architecture. Retain the full glyph-language, historical-script and matched-quality efficiency goals.
