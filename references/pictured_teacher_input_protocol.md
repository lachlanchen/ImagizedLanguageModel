# Can the same pretrained translator read the pictured source?

The Qwen3 8B text reference supplies a quality comparison for transcription-assisted translation. Before deciding whether an offline teacher can supervise reading directly from glyphs, compare a single local Qwen3-VL 8B Instruct Q8 checkpoint on the 18 previously fixed all-comers examples. Keep its pretrained text decoder for this diagnostic. The comparison cannot qualify an independent visual writer.

For each source send either its literal text or its original sequence of black-on-white 32-pixel cells enlarged twofold by nearest-neighbour sampling. Use identical translation instructions and greedy decoding with 160 output tokens. Image requests contain no reference gloss, OCR transcription, path or filename. In a third request ask the same model to transcribe just the picture. Record verbatim responses, termination, request latencies and token counts. Compare transcription character edit distance after removing whitespace only, and count exact source reproductions. Blind the two translations within each example and grade the full sentence before revealing input modality. A study-involved reader has seen the earlier packet and the evidence is limited to 18 passages from a single font. Retain all previous readings. Use one isolated, serial local worker on GPU 0 and release it afterward.
