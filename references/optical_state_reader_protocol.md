# Measuring the meaning retained by a learned glyph-image reader

The native compact writer's attention intervention improved role location without improving complete book translation. A separate control preserved all 480 native OPUS-MT outputs when teacher states were expanded over glyph positions with inverse multiplicity. This experiment now predicts those states and their attention weights from the pictured source. A pretrained decoder serves as a fixed instrument for measuring the visual representation. The complete instrument still uses a text-piece decoder and its training cost is inherited. Independently generated ILM bitmaps are assessed separately.

Train one optical reader for each translation direction on all 28,342 dual-language training passages. The frozen OPUS-MT source encoder supplies target contextual states over the original source pieces. Place the states and log weights on the proved glyph lattice. Training inputs are optical measurements of 32-by-32 glyph cells and two learned boundary vectors. No target-language sentence, text vocabulary, teacher piece boundaries, positional alignments or text encoder is supplied to the reader at inference. The student predicts 512 continuous features and one log mass per valid source position. Normalize squared feature error by corpus target variance per coordinate and by inverse multiplicity so each original piece contributes once. Add 0.1 times mean squared log-mass error over valid glyph positions. Use a 256-wide four-layer bidirectional transformer over a local visual window, AdamW, 12 passes (batch size 96), clipped gradient norm 1, cosine learning rates from 0.001 to 0.0001, one RTX 4090-class GPU, up to 12 GiB allocation and one hour per direction. Use the terminal checkpoint. Report all exposures, elapsed time, and parameters. Target moment estimates use only training pieces. Assess normalized feature error on the two development works.

Measure complete free translations of the existing four-work panel with the visual reader and the original frozen piece decoder operating only on predicted continuous states and log weights. Use greedy generation and the same 128-piece limit for the exact-source teacher and the learned reader. A control exchanges the pictured input with another request in the same direction and work at the nearest available length. A teacher stop at the output limit is not forced. Compare against the prior independent visual writer, source-only blinded reading in both orders, and the intact teaching system. Use the first 12 bilingual pairs per work (96 requests). Report that these books have previously been assessed; this is an interface diagnosis. Use a future untouched panel before promotion. Record both genuine improvements and wrong answers. If the reader beats the swapped source but remains well below the native teacher, quantify the residual loss by language before attempting full visual decoding.
