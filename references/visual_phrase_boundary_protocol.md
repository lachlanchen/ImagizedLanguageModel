# Learning where a visual translation begins and ends

For the three held-out prompts containing 相去, the phrase writer preserved 相 and inserted 距离. The resulting 相距离 leaves the intended distance recognizable but is awkward modern Chinese. The 27 training examples with this source construction provide three different modern expressions and none uses 相距离. A fixed single-cell source boundary and a canonical target phrase discard information present in the actual translations.

The training-only preparation retains 889 real paired clauses. Of these, 833 concern 去 or 伐. A further 33 contain 谢 used for apology or gratitude and 23 contain 举 used for lifting or recommendation. These additional alignments were collected automatically and require whole-clause reading before a new fit. No held-out source or model output enters this inventory. For each pictured occurrence the file records the exact modern expression used by the source edition and its target offsets. Let the recorded expression occupy target cells from \(a\) up to \(b\). A proposed source span from \(l\) up to \(r\) contains the pictured predicate and can also contain one neighbouring cell on either side. For each proposed span we store the sum of edit distances between the exterior prefixes and exterior suffixes. Equality compares the original 32 × 32 bitmaps. Of the 889 rows, **466 have several minimum-cost boundaries**. The cost is a diagnostic of ambiguity. A tie cannot identify a source boundary from that sentence alone.
