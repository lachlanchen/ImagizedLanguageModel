# Do first-glyph errors explain failed book answers?

Fit the comparison specified in [the training decision](first_glyph_book_direction.md). Both new writers start from the same parent and see the same ordered 49,283 physical training examples as the released bilingual control. Give the first or a deterministically selected later action equal extra weight on each of the 22,902 bilingual novel presentations. Later actions include the stop. The remaining training and decoding settings are identical.

Reserve two different extractive questions, each in English and Chinese, on each of 34 passages from four works in the local ZhJpBook library. The questions and accepted source spans were composed for this study. Both languages request a Chinese answer. Preserve all proposed pages, references and original source hashes. Exclude a page before inference if a required nonspace glyph lacks ink or font coverage. Require disjoint accepted physical answer sets. Compare the retained passages to all pages in the supervised fit using 32-cell windows, with every possible start on the reserved passages and stride 16 on training pages. A negative result excludes identical runs of at least 47 cells in this font. Exposure during upstream pretraining remains unknown.

For promotion, the first-action writer must exceed both ordinary training and later-action training on complete pages (two questions in both languages) and on the number of correct first glyphs across those four requests. An empty answer to a nonempty question has an incorrect first action. It must also preserve at least 14 complete CMRC trial pairs and 99 complete familiar historical boards. Evaluate using the normal starting state and greedy stopped image output. Report counts by work, question language, first and subsequent errors, erased questions and source-absent content. The previous book and XQuAD comparisons are development sets. Preserve the released checkpoint if any criterion fails. Compare the same reserved passages with the fixed local Qwen text system using the original decoding and exact-span protocol. The four works and single training seed limit inference about generalization.

In [the Lean derivation](../formal/span_list/FirstActionRisk.lean), each other glyph has nonnegative mass. A wrong greedy choice places at least half the total mass outside the intended physical glyph. The number of completely correct stopped answers equals the number with correct first glyph minus the number that subsequently fail. This identity determines exactly how much downstream error can offset a first-glyph gain. Neither result asserts optimizer convergence or reading comprehension.
