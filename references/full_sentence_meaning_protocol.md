# Learn which complete pictured translation belongs to a passage

The current visual writer preferred the authentic completion over a matched rival on 33 of 64 calibration sites, falling to 31 after exchanging the source. On 84 reserved source-only passages the model reproduced zero translations and 52 capped outputs ended in repeated physical sequences. A locally conditioned first-glyph correction has exhausted its demonstrated benefit. Reusing the same insertion task for longer would leave most of the target sentence supplied during training.

A complete sentence gives a less ambiguous linguistic signal. First evaluate the existing calibration pairs with both full modern translations visible. Keep pair membership, receiver order, chapter separation and authentic/exchanged primary comparison. Record exact source–translation glyph overlap and a length-only control. Have a blinded reader mark cases where either translation fits, the source requires missing context, or the correct assignment can be obtained from a copied name alone. Use an expanded calibration roster if this initial sample is identifiable. Never count these repeatedly inspected pairs as a new held-out language benchmark.

If enough identifiable pairs remain after controlling copied phrases, train a compact visual reader on paired classical and modern sentence images from distinct training chapters. Use the complete translation only as a training target. The source representation predicts a continuous representation of the translated phrase. Against an equal-capacity local-image control, evaluate authentic versus exchanged sources and restrict a second analysis to matched glyph overlap. Combine this language objective with direct conditional image likelihood for the modern output and teacher-forced to self-generated prefix exposure. Verify on independently rendered passages and entirely unprovided target histories. A positive contrastive score establishes a reading result only. To advance the independent model, require a chapter-replicated improvement in the acceptability of complete generated translations as well as lower physical glyph edit distance than copying the source.

If readers cannot distinguish the full pairs, inspect parallel passage alignment, remove demonstrably missing context in training data and obtain a fresh chapter split. If readers pass but whole-sentence generation fails, measure where source discrimination is lost between the visual reader and the first clause the writer supplies. Keep output examples in their original pixels, including repetitive failures. Source familiarity, measured runtime, all model components and GPU memory are part of each comparison. The 4B text teacher's format-sensitive pilot does not qualify it for bulk pseudo-labeling.
