# Learning language from rendered text

Rust and colleagues' PIXEL reads a rendered line as a sequence of patches. In the released pretraining code the decoder predicts masked image patches. Its squared error is averaged over removed patches after optional patch normalization. The experiment asks what information transfers to syntax and meaning across scripts. The [downloaded 32-page PDF](language_modelling_with_pixels.pdf) is the unmodified paper by Phillip Rust, Jonas F. Lotz, Emanuele Bugliarello, Elizabeth Salesky, Miryam de Lhoneux and Desmond Elliott, distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). [Paper](https://arxiv.org/pdf/2207.06991) · [Pinned PIXEL objective](https://github.com/xplip/pixel/blob/1b0da2942ac0da13b98fd31dbbd720f9a438d8b7/src/pixel/models/pixel/modeling_pixel.py#L1249-L1264)

PixelGPT is a separate autoregressive project. Its implementation shifts continuous patch targets forward one step. The combined model can also predict text tokens with a separate loss. This is the closer comparison for an autoregressive glyph stream. PIXAR studied readability during autoregressive pixel generation. Together these papers make prior work on both visual reading and visual writing explicit. [PixelGPT paper](https://aclanthology.org/2024.emnlp-main.182/) · [Pinned next-patch implementation](https://github.com/ernie-research/pixelgpt/blob/6307571fd55ebc2ae800da5005692a668baa8079/src/ernie_pixel/modeling_ernie_pixel.py#L1277-L1309) · [PIXAR paper](https://aclanthology.org/2024.findings-acl.874/)

The present ILM has a different output constraint. A context model chooses a visual code, a neural motor emits 32 × 32 pixels and a reader feeds those pixels back. Choosing from a fixed repertoire makes stroke formation reproducible and limits invention of new shapes. For fixed weights each code has a deterministic image and feedback vector. Compiling these functions permits an explicit prediction about inference cost. The same images and stops must survive optimization at the actual numerical precision and batch size. New sentences still require new context decisions. Our timing comparison uses the same ILM before and after compilation. It does not measure a speed ratio against upstream PixelGPT. [Experimental protocol](../glyph_stream_cost_protocol.md) · [Exact-arithmetic equivalence](../../formal/span_list/GlyphStreamReuse.lean)

A second result comes from the paired print intervention. A change of typeface can destroy an answer while leaving its intended meaning unchanged. Restoring the precise original input lets us identify the remaining error downstream. Human gaze-contingent reading studies motivate looking at small groups of adjacent glyphs as a future learned unit. The eye-movement experiment manipulated how much text around fixation remained legible. Its result supplies an experimental analogy; direct evidence about our model comes from controlled optical inputs and free outputs. [Inhoff and Liu, 1998](https://pubmed.ncbi.nlm.nih.gov/9483822/) · [Previous visual-span experiment](../optical_span_feedback_protocol.md)
