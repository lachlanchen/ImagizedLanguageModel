# Reading an answer span directly from passage images

The native model's two 言 answers expose a disagreement between its proposed writing and the image returned to the reader. A bounded extraction experiment asks whether a reader can learn to select a complete answer when the passage already contains its physical glyphs. The reader returns copies of the selected contiguous input cells. This removes stroke synthesis as a source of answer errors. The experiment concerns passage-conditioned reading within a single rendering, and supplies no free-writing, etymology or script-transfer credit.

Use only the 9,023 QA examples and 2,127 passages from the original training partition. Keep the original autonomous cohort, development references and DRCD untouched. Assign the first 425 groups in SHA-256 order of the bytes of the string `visual-extraction-v1/<group>` to this experiment's held-out partition. All questions sharing passage pixels stay together. These groups are unseen by this new reader, but were available to the separately trained native model. Extract passage and question cells from the fixed prompt layout. Retain the exact full answer pixels as supervision, selecting the earliest matching span if an answer occurs more than once. Report multiple occurrences. Do not pass answer pixels, reference lengths, IDs or group names to prediction.

For each physical position compute question/passage glyph and short consecutive-run overlaps, overlap on either side at several distances, relative position and coarse ink coverage near the boundary and in the question. Fit two depth-limited histogram gradient boosting classifiers for the beginning and end positions. Sample both true boundary positions and 48 uniform positions per question with seed 202611210. Each classifier has 64 iterations, 15 leaves, learning rate 0.1, L2 penalty 1 and at most 64 bins. Use the learned boundary log odds and an add-one-smoothed training length count to choose jointly among all valid contiguous spans. The split, candidate spans, tree budget and feature implementation are fixed before the full fit. A blanked question and cyclically exchanged questions within the same passage control for answer position, length and reading the passage alone. Score each complete returned raster against the original full target. A swapped-question comparison uses only changed questions.

Count complete exact answers, total questions, emitted lengths and overlapping-glyph sequence length on a subset only if declared separately. Report exact accuracy for normal and blanked questions over all cases, and normal versus swapped on the paired subset. For either difference resample whole test passages with replacement 10,000 times, seed 202611211. Credit question-conditioned extractive learning only if normal exact accuracy reaches 5% and both lower 95% endpoints exceed zero. Record the full scores even if this criterion fails. Preserve original outputs for a fixed sample in split order and SHA-256 of every predicted stream. This comparison cannot establish a matched-quality speedup against Qwen or generation of any answer absent from the supplied page.

Use a single CPU process with two numerical threads and no GPU, at least 48 GiB available RAM at entry, 24 GiB retained and a 4 GiB process ceiling. Permit 20 minutes end to end. Preflight authentic train-only examples through feature extraction, both actual classifier fits, span decoding, and disk round trip, then discard those weights. Preserve all original neural states and workers. If the reader succeeds, report the trained passage-extraction capability with its measured cost, as one component. If it fails, retain the outputs and reject this recipe as sufficient for the registered claim.
