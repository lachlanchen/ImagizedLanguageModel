# Generating the next image with uncertain source alignment

On the first fresh cohort the single-path fixed-alignment writer stopped on 796 of 1,022 renderable translations. The editor has several different ways to write the same glyph. An action chosen at one cursor can repeatedly insert a mark even when most probability over complete emitted images supports advancing. Test a decoding change using the same frozen weights and same inputs. Maintain a distribution over possible source cursors consistent with the emitted physical code sequence. Sum over all intervening deletions, combine copy and drawing mass for each physical prefix, and compare a complete output code with termination. Keep four physical prefixes per within-glyph step. Record how often the surviving mode dominates every pruned prefix's upper bound. Check probability conservation, equivalence of complete prefix probability to the training likelihood, stopping, actual bitmaps, quote fidelity and rate of edits with chapter intervals. The candidate set is constructed from physical measurements and the learned continuous-context drawing network. No target enters free generation. Both weights receive both decoders. Prefer the summed-prefix decoder only if both fresh cohorts improve over the same fit's single-path generation and local rule, preserve 99% exact quotations and produce a complete long mixed answer. These same-cohort interventions require independent confirmation before deployment.
