# Ranking a larger set of physical answer strips

With one proposal per reader, 84 of 384 fresh human questions lacked a correct candidate. At depth eight, 46 of these references became available. Test whether the additional candidates improve emitted answers while preserving the correct attribution of exchanged names.

Train a question-conditioned scorer of the union of the four heads' eight best physical positions. Count each position once and combine probabilities for physically identical output strips. Features may include shared contextual states at the endpoints and within the span, question-conditioned page summary, normalized endpoint scores, length and position. Reference answers, source IDs and corpus tags are training or evaluation metadata only. Compare a matched depth-one fit, shuffled supervision, and all frozen top-one readers including the preceding selector. Use the existing local pretrained visual reader, with at most 20,000 training cases and 16 epochs per fit on one RTX 4090 D. Reuse the same frozen feature extraction for all arms.

Reserve training-split human paragraphs and new paired DuIE subjects for validation. Exclude the new exchange subjects from all previous local specialist, selector and reranker training. Select the earliest epoch maximizing the equal-weight mean of natural exact accuracy and complete exchange-board object accuracy. Freeze fits before scoring a second sample of up to 192 natural questions from each corpus, taking one question per paragraph, disjoint from preceding test paragraphs. Report actual sample sizes. Evaluate the existing 384 questions separately as a development diagnostic, including the 46 newly available references. Measure exact replies in both generated word orders, termination and all name exchanges, plus historical name substitutions. Retain all trials and examples.

The main model must beat both the frozen generic reader and matched depth-one fit on the second fresh sample, retain at least 34/48 human factual replies in both word orders, 79/128 complete exchanges and 37/48 reordered boards. Evaluate per-corpus results, paired gains and losses and oracle coverage. If broad or exchange retention fails, diagnose actual output boundaries and wrong-name selections. A pass establishes bounded extractive transfer. Independent book writing and end-to-end compute efficiency need their own experiments.
