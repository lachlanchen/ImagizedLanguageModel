The independent modern writer generates some missing expressions but has no measured ability to return a requested historical form. Test the original deployed model on structured evidence that fits its existing 48 physical input cells. Present a pictured English or Chinese request in the first 24 slots. The other 24 contain four shuffled records plus padding. Each record contains a modern character, a three-cell Chinese stage label and a historical source image. A plate crosses two different character families with the same two attested stages. Each family-stage combination has exactly one exemplar on that plate. Original source identifiers and field labels are retained for scoring and provenance. Only physical pictures enter the model.

Prepare 6,000 training plates and 600 development plates from the existing family- and raster-disjoint historical partition. Use seeds 714 and 715. Present both languages, both characters and four requests per character and language (either stage alone or the two in each order). Keep the evidence identical across all sixteen requests. Vary row order and historic exemplar. Reject ambiguous equal character images, equal historical images and duplicate plates. A pass requires at least 90% exact whole stopped answers in each language and length and at least 80% both-correct reversed-order pairs on development. Score correct output length, contained reference shapes, question-erased ceilings, and source identity separately. This is a source-grounded task in a known page layout.
