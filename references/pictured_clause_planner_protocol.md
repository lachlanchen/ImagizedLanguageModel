# Separating where a request points from what the page says

The ordered causal writer produces 118/312 complete answers on practiced relation combinations and 3/136 when the two relations have never appeared together in compound training. Test a shared clause writer with a learned visual request planner. The question alone supplies its clause count and predicted spans for its headword and ordered relation names. The model sees no native character identities or relation vocabulary at inference. For a predicted two-clause response the same writer receives the original passage and each physical headword–relation slice in turn. For a single request it receives the original question. All outputs come from autoregressive image decoding. Each returned clause must stop, and the complete answer is limited to the same 48 cells.

Supervise spans only on training questions. Keep both withheld relation combinations absent from all compound training. Train on two-clause requests that name their arguments in either ordinary surface order or with the second instruction stated first. Compare authentic predicted plans, oracle training-style slices on held pages, and reversing the predicted clause assignment. Test novel paraphrases with inverted surface order where only explicit ordinal words determine the required answer. Match the original compound and short question cohorts, open answers, authentic historical controls, and real human questions. Log count, span, physical writing and model costs separately. The oracle uses evaluation annotations only in its labelled diagnostic. This bounded experiment tests two-clause composition and cannot establish general discourse or compute savings.
