# Does a glyph dialogue writer learn more efficiently than a subword Transformer?

Compare the released direct and word-code writers with a randomly initialized encoder–decoder Transformer trained on the same 8,000 batches of 32 complete CoQA turns (seed 710491). Train a case-sensitive byte-level BPE tokenizer of 4,096 symbols only on fitting passages, questions, history and replies. Preserve passage, question and history segments, order, punctuation and held answer lengths. Use two 96-dimensional encoder and two decoder blocks, four attention heads, 256-dimensional feed-forward layers, tied input/output embeddings and learned source segment embeddings. Teacher-force answer generation with an explicit end marker, and supervise the source evidence endpoints on the same annotated turns. Greedy evaluation has 96 answer subwords and no reference access. Shorten no eligible source. Cap the run at 50 minutes and 12 GiB allocated VRAM on GPU0. Record software and per-stage time, GPU energy and peak allocation. Record a failure if the cap is reached.

Score every registered held turn with the same normalization, question exchange, passage exchange and strict composition criteria, using identical denominators. Report the official four-reference development scores and the subset with absent wording in all four answers. Measure paired differences by resampling stories. The visual writers have inherited supervised optical/passage weights and a word-copy route. The token Transformer starts fresh and generates all subwords. This tests the complete systems under equal dialogue exposure. It cannot attribute any difference solely to representation. Neither treatment represents a modern pretrained 8B instruction model. A claim of compute advantage requires comparable quality, complete accounting of inherited costs and a separate input-matched architecture control. Evaluate the final checkpoint without tuning it on this comparison. A visual deficit or failure of either system on novel phrasing keeps the efficiency hypothesis open.
