# Teaching a visual translator where a grammatical role was written

The frozen broad literary writer gives a matching role five percentage points more attention than expected from permuting its labels. For English predicates the excess is only 1.43 points. The experiment asks whether strengthening that association during training improves the meaning of a complete answer on new works. Shared subject or object tags alone cannot distinguish two people with the same role. An increase in alignment can coexist with poor translation.

## Matched learning comparison

Start three fits from the identical released 1,688,480-parameter broad writer. Use the 28,342 bilingual pairs from its 21 training works together with the same replay and four-pass target schedule. Put each model through the same shuffled minibatches, AdamW optimizer, clipping at unit gradient norm and learning rates 0.00016, 0.00012, 0.00008 and 0.00004. Use the final checkpoint of each fit. Retain the original broad writer as a fixed comparison. Allow up to an hour and 12 GiB of allocated memory per arm on a single 4090-class GPU.

All arms optimize the observed glyph and stop likelihood. The supervised arm also assigns probability to the target role under the current last-layer cross-attention. Split a window's attention equally among its occupied input cells and sum over the cells with the corresponding source role. Add the sum of the negative log matching masses multiplied by 0.10, divided by the number of supervised glyph and stop positions in the minibatch. The second intervention uses a fixed, independently seeded permutation of nonzero source tags within each source sentence and direction. Preserve all role counts, labelled positions and eligible target positions. The third arm uses the original glyph likelihood alone. Preserve the same inputs and output inventory in all arms. Inference takes the source image and translation direction. Training tags and target prefixes are absent during free writing. Record the number of tags changed by permutation and the actual per-arm supervision, updates, memory and time.

## Held assessment and decisions

Reserve 48 previously unused single sentence pairs per work from *The Great Gatsby*, *The Republic*, *Water Margin* and the bilingual Bible. Write in both directions, for 384 requests from 192 paired sentences clustered in four works. Both directions share a source pair. Score every request with the existing source-only bilingual model assessment in both orders, hiding writer identity and collapsing identical candidate wording. Include the quantized text comparator, corpus references and shuffled foils. Repeat the assessment with the supplied reference identified. Archive the source PNG, direct output PNG and stop decision for every neural writer. Compare complete meanings with controls by paired resampling at the work level and disclose the small number of clusters.

Qualify a candidate for further natural-language testing only if the true-role arm beats both the shuffled and likelihood-only arms in the source-only assessment, with strictly positive lower bounds in both paired 95% intervals, corroboration in the reference-informed counts, at least 108 of 118 complete controlled families and a stop on every new request. Always report the frozen starting writer's scores. If alignment rises while meaning stays flat, close this intervention and move the learning signal to complete bilingual propositions, with a matched control and a new independent panel.
