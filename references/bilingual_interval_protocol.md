# Bilingual reading through source intervals

Keep the visual parent, its optical map and its first eight contextual layers fixed. Both fits update the last four contextual layers and the endpoint projection. Each pass uses the same seed, example order, 24 requests per batch, AdamW learning rate 0.00002, gradient norm limit one, bfloat16 matrix operations and float32 likelihood. Optimize the negative log probability of the union of all acceptable intervals among all source intervals of width one to 48. Drop entire incomplete exchange cycles so that both fits see identical English questions, passages and accepted intervals. Use one pass and one final checkpoint per condition. Allow 20 GiB allocated memory and 20 minutes per fit on GPU 0.

Evaluate new works and a separate modern source with two different facts on each passage and two languages for each fact. Freeze the new packet before examining either fit's outputs. For the literary packet require more exact English answers and more complete four-request passages than both the parent and exchanged control, and at least the parent's count of exact Chinese answers. Separately report all of these measures on the modern source. Require more correct English answers and at least the parent's correct Chinese answers there as well before selecting the new evidence reader. Report question erasure, prior development works, speed, and the outcome of feeding predicted evidence to the independent causal writer. The full writer remains the interface for generating historical and non-extractive replies.

For the writer transfer comparison, replace the released writer's pictured passage with the interval returned by each reader and retain the original question. Compare its freely stopped reply with its output from the full original page. Pass no target to either inference step. Compare exact image strings, including stopping, on the same cases. This intervention tests the use of predicted evidence when the reference answer is in the passage.
