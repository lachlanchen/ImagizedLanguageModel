# Writing a supported Chinese proposition after a fact changes

A source-aware captioner returned 188 of 192 familiar historical captions but only 21 when reworded. It returned no complete answer requiring absent content ink on two open cohorts. Test an intermediate linguistic capability: generate a new grammatical proposition that binds the requested relation and its arguments in a natural Chinese passage. DuIE supplies source sentences and annotated relations. Modern input is rendered to the existing physical page format. A whole answer is excluded if it can be quoted verbatim from its source or request.

Pair original sources with passages in which two distinct entity mentions exchange identities. Keep the physical character multiset and question fixed. Ask complementary questions about the same passages. Keep both edited and original counterparts within a split. Use the official development split, exclude training sources, headwords and complete triples from the measured development pairs, and exclude ambiguous or overlapping mentions. Evaluate both a subject contrast over two excerpts and a relation contrast within a single excerpt with two distinct annotated values. Include reworded requests on the same held pages. Include an independently worded short challenge that combines two relations into one new sentence, and a regression check on genuine open questions and historical captions. Labels for an edited passage describe the counterfactual page, not a claim about the world.

Compare the frozen existing pointing writer, genuine supervised continuation, and equal training after exchanging requests on the same page. All learned arms start from the hash-verified pointing checkpoint. Preserve the same print bank and direct source-image actions, use no source text, OCR, label lookup or text decoder in deployed inference. The answers have an explicit stop. Count exact canonical images, recognized grammatical equivalents, presence and order of the right arguments, wrong arguments, both questions for one page and both pages following an exchange. Inspect errors in a fixed order and distinguish partial answers from new supported statements. Use one RTX 4090 D, at most 8 GiB allocated and 20 minutes per fit, with a single serial owner. Further language claims require transfer beyond the known response constructions and the previous open-answer cohorts. Preserve every preceding checkpoint.
