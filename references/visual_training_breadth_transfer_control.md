# Pretrained translation on the same source pixels

After freezing the paired training comparison, run the existing OPUS-initialized pictured path writer on all 96 archived source PNGs. Compare it with greedy translation by the original text model at the same pinned revision and with the independent broad writer. Score all three in a separate randomized, two-order comparison including the stored Qwen answer, supplied reference and unrelated foil. Preserve both assessments. Use a 128-step limit and learned stop, record surface counts and spans, and retain every optical output PNG. Verify a fixed CPU sample against GPU images. This control asks how much meaning the same print inputs support with inherited language parameters. It cannot establish that the independent learner acquired those parameters' capabilities.
