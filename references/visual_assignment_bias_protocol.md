# Does a correct joint assignment imply two correct independent readings?

Matching two sources to two answers cancels a source-independent preference for one answer. Free writing makes a decision for one source at a time. The original strip body correctly matched 164/168 role pairs jointly, while a writer with the true unordered target inventory reproduced both answers for only one of 84 identical-inventory pairs. Before inspecting individual score differences, measure both separate choices on the four new books, on all controlled roles and on the 84 pairs with the same strip multiset. Score the complete supplied candidates, including stop. Preserve original and length-normalized log probabilities.
 
For a baseline available without the competing test source, estimate the preference between the two complete candidate translations on 16 source images from training. Select training sources only by physical source length and a fixed seeded order. Select one shared set per pair using its average source length. Subtract the background mean score of each candidate, then count pairs where both independent choices are right. This baseline still receives the two candidate answers. It is a diagnostic of target preference and cannot be credited as autonomous generation. Do not fit parameters or tune the background size. Report all pairs, ties and both-choice counts. A Lean identity states exactly when a positive joint match implies two independently preferred answers and when changing a common target prior preserves the joint score.
