# Translating pictured source spans once

The earlier ordered channel expressed none of 96 complete new book meanings, although 91 sources could be retrieved from translation images. It repeatedly emitted the same content. Learn translations of contiguous pictured phrases and make each emitted phrase consume its contributing source span. A finished answer must cover every source strip exactly once. Infer wordless links from the two previous HMMs, count consistent phrase pairs up to four optical strips per side, and learn a smoothed target bigram distribution from the same 497,775 parallel pictures. Store phrase pairs observed at least twice and retain up to eight candidates per source. Back off to the trained lexical table for uncovered individual strips. The only interpreting vocabulary at deployment is the trained optical repertoire. Phrase-based translation provides the statistical precedent. [Koehn, Och and Marcu](https://aclanthology.org/N03-1017/)

Freeze four unused works and their first twelve eligible paired passages before fitting, with prior book and training-side exclusions. Compare three frozen writers (neural, unordered and ordered) with phrase coverage on both directions. Use source-only, order-reversed blinded assessment, a quantized text comparator, the provided reference, unrelated foil, and the existing 236 paired role/negation prompts. Keep raw outputs, count complete source coverage, literal reference content, repeated content, output completion, and actual spelling of proper names where the source and reference preserve the same spelling. Report scope if that sample is small. Track valid reference repetitions as well as overproduction. Calibrate phrase scoring on development only. Require more complete free book meanings than all controls, with no decline from the neural control in exact paired polarity and exchanged roles, before claiming a general improvement. If complete answers remain weak, measure whether the reference target strips are available among phrases attached to the source. Preserve held output and failed criteria.
