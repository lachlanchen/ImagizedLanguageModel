# Does changing the pictured evidence change the written answer?

A writer can recognize a typeface and still ignore what its source says. On the separately fingerprinted CMRC trial questions, test the two visual correspondence fits with their shared frozen language writer. Keep all human questions and swap the two answer strings in the source passage. The questions, surrounding text and document length remain fixed. An exchanged passage is a counterfactual document.

Include all covered pairs where each question has one distinct recorded answer, both answers occur exactly once, neither overlaps the other, and neither appears in either question. Require two through eight non-space characters of the same broad class, either all Han characters, all ASCII digits or all ASCII letters. Exclude unequal-length strings so both original answer locations stay fixed. Exclude every board that overlaps a reserved passage as in the original trial screening. Score the same eligible boards across regular, HanaMin and FandolSong. A complete board needs both original and both exchanged answers in the corresponding order, with four autonomous stops. Also report exact answers on each version, output changes on the same question, per-board identifiers and the number eliminated by each rule. Swapping equal-width phrases can produce awkward or factually false prose. This test measures sensitivity to written evidence; it permits following a learned source position.
