# How many complete replies can a better span selector recover?

The frozen reader ranks an accepted short fact in its top 32 on 122/192 English and 119/192 Chinese questions. The English writer also fails on many correct facts. Before fitting a selector, measure the attainable end-to-end result on the same diagnostic pages. Fix the reader, the fact-only writer, their release cells, the 256-decision limit and the complete stopped-image criterion. Take the first 32 legal score positions with the original flattened index breaking exact ties. Generate the free answer for each distinct rank, including repeated physical spans at different locations. Keep references outside both neural calls. Reconcile rank one against every original saved fact location, answer hash and stop flag. Count questions for which at least one candidate yields a complete accepted answer. Separately count those for which the same candidate also contains exactly an accepted short fact. Count jointly attainable question pairs. This is an oracle over model executions on a previously seen diagnostic set. A new selector needs separate fitting data and fresh confirmation. Use one GPU and at most two GPU hours. If exact fact and answer are jointly attainable on fewer than twice the currently solved questions in a language, prioritize the writer or candidate generator there. Otherwise test learning the joint boundaries. Measure the finite-set capacity bound in Lean.
