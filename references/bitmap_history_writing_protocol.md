For each missing-image action derive the neural distribution over familiar training-answer shapes. Starting from that distribution, look up one, then two, then three, then four previous emitted glyph images. For each observed history, interpolate the empirical next-image distribution with weight min(0.8, n/(n+8+d)), where n counts occurrences whose successor is in the unchanged emission set and d the number of distinct such successors. Zero observations leave the previous distribution in place. Select its modal image. Inference consumes only the actual answer prefix. Writing a cell returns an exact stored bitmap. No target or source-string transcription enters the decoder.

Require at least 15 exact complete answers in the 300 input-absent cases and more than rotation to claim an independent composition advance. Held-out scores cannot select interpolation weights, corpus filters or history length. A conditional gain alone motivates learning when to use that signal.
