# Retrospective first-policy separation

This CPU-only diagnostic opens the source lexical projection as an offline
instrument. It is not an independent ILM runtime or an accuracy result for
learned image generation. No body forward call, optimizer update, new answer
or training example is produced. The complete answer trials are already scored;
all first-state analyses are retrospective, not new held-out evidence.

Use all32 first reserved questions from both the contextual and readout-only
conditions, and all32 second reserved questions from both the balanced and
unchanged-parent conditions. Authenticate the actual saved tensors and scores.
The latter two conditions must have bit-identical first states because their
reader is unchanged. Do not select cases by teacher success or image quality.

Apply the authenticated original source output matrix to each actual saved
initial state. Round matrix weights BF16 then FP32 as in the earlier source
diagnostic, with CPU FP32 linear algebra, and record top-two margins. This is
the unmodified lexical head on the actual possibly adapted body state; it
does not establish what the unmodified whole source model would answer.
Retain partial/empty Unicode winners and explicit terminal winners. Compare
only the first decoded character with allowed reference first characters;
do not turn a first-character match into complete-answer accuracy.

Separately compute the actual first emitted glyph's canonical pixel equality
and foreground F1 against supported reference first forms. F1>=0.95 is a
physical similarity measure, not a Unicode identity classifier. Keep unsupported
reference forms and empty emissions explicit. Existing clear complete-answer
grades remain unchanged. Report joint teacher-first/physical-first outcomes
and any cases where the matched unchanged reader gives different first states.

No source lexical tensor or selected word ID is added to the learned runtime.
Use the common model/build mutex, hidden CUDA, low measured memory pressure,
48 GiB host entry reserve and24 GiB live reserve. Reuse the shared source
archive without saving another matrix. Findings may guide a subsequent
registered training experiment but must not silently become fitting targets.
