# Can the image reader locate its own support interval?

On 1,834 copyable positions the previously supplied rationale corrected 135 winning copy decisions and spoiled ten. Test a deployable modification using only the writer's own endpoint logits. Let left and right endpoints be independent categorical draws conditioned on their order. For each passage word compute the exact probability of inclusion using one prefix and one suffix sum. Weight each of its four pointer-edit alternatives by one plus three times this probability. Candidates in the question and history retain unit weight. Keep channel selection, recurrent generation, all weights and greedy decoding fixed. Use the final human-evidence visual writer selected by experiment design, its matched byte writer, and the corresponding original human-evidence outputs as controls. Evaluate complete original and exchanged prompts on the previous 758 long-story turns and independently on all remaining official-development stories above 448 words satisfying the same print and separation constraints. Include every qualifying turn and all four references. Estimate paired whole-story F1 intervals and report computational complexity, exact-match differences and absent-phrase performance. Require positive lower bounds on both story sets for a reliable improvement claim. If performance fails, distinguish the value of the human rationale from the value of the estimated interval. The new decoder is an optional inference mode until supported on independent data. Preserve the original reported fit.
