# Can a longer writing action preserve a bilingual sentence?

A previous independent writer conveyed the complete source proposition on one of 192 fresh book requests. Its matched likelihood control answered two. Both could already draw legible glyphs. This experiment asks whether an independent language body can learn a better sequence of writing decisions when a single decision can produce several adjacent glyphs.

Two fresh encoder–decoders train on both directions of the same 240,000 OPUS-100 pairs and 28,342 parallel book passages. The source is an ordered series of 32 × 32 glyph images. The control emits one glyph per writing action. The comparison adds up to 2,048 frequent strips per direction, learned by adjacent-pair merging of training bitmap identities. Strips span at most eight cells. Every single-glyph action remains available. Both networks share the architecture, the initial parameter values, the frozen physical writer and the order of examples. Each has its own optimizer and trains for four complete passes. A writing action is discrete. No text-trained language weights or decoded text enter either model. Calibration, efficiency and language fidelity require separate measurements.

Freeze four previously unused works and 24 bilingual sentence pairs per work before fitting. Translate all 192 pictured requests greedily in both arms with a 128-cell ceiling. Archive the original input and output PNGs, including empty and truncated answers. Exchange sources within direction for a third condition. Count complete source meaning under the existing blinded two-order assessment, with Qwen and reference controls. Require a positive lower book-bootstrap bound on the paired gain, no decline in either direction and more candidate successes with the real source than with exchanged sources. Report both totals even if the comparison fails. Inspect the first registered pair in each work without selecting for success. Report action counts, single-card time, training throughput and peak memory. These measures do not establish compute savings at matched quality.

Use GPU 0 serially, less than 20 GiB allocated per fit, two CPU math threads and a three-hour bound per arm. Save restartable epoch checkpoints. A failed assessment leaves the free-writing claim open. A positive result warrants a larger, independently judged book sample and a matched-compute text baseline.
