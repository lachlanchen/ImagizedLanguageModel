# Free generation within the parallel training domain

The book test deliberately changes the source domain. To assess the practical reach of the same completed independent writers, generate answers for all eligible pairs of the original OPUS-100 test sample in both directions. Verify the original test digest and exclude any side duplicated among the 268,342 fitting pairs, both by bitmap and after folding case and removing punctuation and spacing. Freeze the resulting requests before generating. Compare the aligned, shuffled and unchanged writers without any fitting or decoding changes. Assess full source meaning using a source-only model judge, with two hidden candidate orders, the proposed reference and a cyclic unrelated target. Use CPU to generate the PNGs. Archive every input and output plus stop, length and individual grades. Report the first aligned credit in enumeration order. The earlier OPUS sample was used for other models and is a within-domain secondary test. The four unseen books remain the primary test.
