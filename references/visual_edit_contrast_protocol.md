# Predicting complete drawings during sentence editing

The preceding writer reproduced 37,427 of 37,451 requested shapes when given the physical measurements, but predicted the correct drawing 3,816 times from the supplied correct language history. The default insertion-limited model had a higher edit rate than local edit counts on both original rosters. Test whether contrasting whole proposed glyphs in training improves independently generated sentences.

Start both arms from the released 2,026,237-parameter sentence editor. Freeze the renderer, input encoders, initial state, previous-action embedding and insertion predictor. Update the recurrent decoder, action projection and conditional ink predictor. Use the same saved 48,000 translations and 12,000 quotations in each of four passes. Use AdamW at 0.0003, clip gradient norm at two, and retain only the final fit. Both arms score the same sampled negative drawings, with auxiliary loss coefficients zero and one. Keep the original action cross-entropy and three times the mean four-bit pattern loss.

For up to 256 uniformly sampled recorded draw positions per minibatch, score the positive and seven cyclically shifted draws from a shuffled set of positions. Each score is the sum of twelve conditional group log probabilities. Mask alternatives identical to the positive landmark sequence. The auxiliary term is the mean negative log softmax probability of the positive, with no output inventory or negatives at inference. Use the original greedy action, four-path internal drawing search, learned insertion count and stopping.

Score both fits on the original first chapter roster and 2,048 new requests from chapters absent in every prior classical editing roster. Select the new examples by a fixed row hash before rendering, with the same 96-cell source ceiling, no reference-length filter, no overlap of source images, and unsupported requests retained. Also run the original unmodified editor on the new roster. Compare complete translations, quotation, longer mixed answers, physical edit rate, source exchange and a training-local edit control. Estimate paired differences by resampling chapters 2,000 times. Record supplied-history drawing identity in both arms. Require a positive lower 95% bound in fresh edit-error improvement over both equal training and local counts, at least one exact longer mixed answer and at least 99% exact quotations on all requests. Report the fraction of exact translations requiring actual changes. Failure retains the existing default checkpoint. Use a single RTX 4090 D and the existing 8 GiB GPU, 6 GiB host RSS, 24 GiB available RAM and 35-minute phase limits.
