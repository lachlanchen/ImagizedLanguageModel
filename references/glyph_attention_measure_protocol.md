# Preserving a bilingual representation on an image lattice

A bilingual translator may devote a single source state to several written glyphs. A visual encoder can instead produce a contextual vector at every pictured cell. Simply repeating a word's original state across its cells multiplies its contribution to decoder attention by its written length. For a piece occupying r cells, subtract log(r) from the attention logit of each copy. Copies then sum to the original unnormalized mass for every query. The weighted value sum and partition function are both preserved. The log multiplicity plays the same algebraic role as a degeneracy term in a partition sum. Lean checks the numerator and denominator identities at arbitrary rational resolution and with signed values. Floating-point implementations require an empirical correspondence check.

Test that interface on all 240 pairs in the two development books in both directions. Use the two immutable OPUS-MT teaching checkpoints and their actual contextual source states. Allocate one image-lattice position per written glyph and two boundary positions. Partition these monotonically by the teacher piece offsets, reserving at least one position for every piece and the final stop. Count any unrepresentable request. In this diagnostic, the teacher supplies states, boundaries and target decoding. No source image encoder has been fitted by this comparison.

For each pictured passage compare the original teacher input, unweighted copies and corrected copies. Measure the maximum and mean absolute difference in reference-next-glyph-piece log probabilities, disagreement of top predictions, and equality of every free greedy output piece including its stop. Use only the correct target prefix in the probability diagnostic. Generate a separate freely written sequence of at most 128 pieces per condition. Report both target directions separately. Verify that complete outputs and stops are identical for every corrected request before using the construction as an exact reference for a learned image interface. Preserve all discrepancies. If floating-point rounding changes a free answer, keep the per-position error, the first differing output gap and the actual answer difference. Next learn the latent positions and their mass directly from pixels and score that model independently. A reproduction with known teacher states establishes the interface, not visual language acquisition.
