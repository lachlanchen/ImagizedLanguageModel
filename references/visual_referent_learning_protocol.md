# Reading the participant across a relative clause

A reader trained on local heads recovered the pronoun in all 84 subject-cleft challenges. English dependencies encode an additional relation between a relative expression and its antecedent. The test here asks whether changing the target of the same image likelihood is sufficient to recover both participants and write their event in Chinese.

Start both readers from the same authenticated context locator. Use the original EWT and GUM official splits and reserve the entire GENTLE treebank as an external test. Deduplicate cropped and full sentences across splits and exclude any GENTLE sentence seen by the parent. In eligible transitive clauses use an explicit enhanced ref edge when both ends lie inside the pictured window. One arm learns the original local heads and one the resolved heads. Supply only the original glyph cells and the event's verb mark. Use the existing disjoint-interval decoder. Draw 24 linked clauses, 32 ordinary actives and eight ordinary passives in each batch, with replacement. Fix 1,600 AdamW updates per arm, seed 602173, peak learning rate 0.00025, a 60-step warmup and cosine decay to 15%. Use final weights. Limit each fit to 900 seconds and 12 GiB allocated.

Score both spans at their correct occurrences. Report linked and ordinary clauses on the official and external tests, including changes on individual cases. Test both cleft types and both roles of a reversible transitive event. For Chinese writing, freeze an existing independently trained bilingual writer. Compare the complete pictured English sentence, the three English ink spans selected by each locator in actor--verb--undergoer order, and annotated spans as an upper diagnostic control. Use a fixed blank and sentence terminator in the three-span input. Measure exact stopped Chinese images and reversed meanings, retaining raw output and all failures. Restricted writing experiments use affirmative events. General book translation is a separate measure. No training on challenge sentences or external results.

If natural linked accuracy improves, report any loss on ordinary clauses before deciding whether to use the reader. If source selection improves without downstream writing gains, identify the first stage at which the intended event is lost. Model and manuscript claims require observed outcomes.
