# Writing the stated fact and its historical form

The previous writer learned all 39 supervised phrase choices and conveyed zero complete translations in eighteen new book readings. This experiment trains the deployed writing decisions on complete supervised answer images. It uses a more structured task with different data. Its result cannot be compared numerically with book translation.

The input comprises a pictured question and an illustrated entry card in the published 32-pixel format. Four delimiter images identify headers and fields. Every field supplies its pictured name and value as possible copy spans. A recurrent writer can select any visible heading, field name or field value, emit one of the 64 most frequent training answer glyph images, or end the answer. It receives raster appearance and exact pictured heading and field-name matches and positions in the question. It receives no reference answer, requested field identifier, per-character text identity or output length at inference. The writer begins from its learned initial state and reads back the appearance of its last emission. All outputs end at a model stop or the 72-action limit.

Use all 8,920 training examples for eight shuffled epochs per arm. Select the shortest physically valid segmentation of each answer during supervised fitting. Sum the probability of all actions emitting the selected span at each step. The comparison arm receives a fixed derangement of the eight complete answers on each card. Both writers start from identical random weights, use the same batches, and receive the same number of presentations of every question, card and answer image.

Evaluate the final checkpoints on all 1,136 previously reserved family-disjoint answers with both published question phrasings. Count exact complete bytes with a learned stop, exact final historical form, factual span, and all eight answers on a card. Swap requested head, field and stage independently. Swap corresponding field payloads between the two entries with the headings and questions fixed, and score the newly warranted complete images. Compare with a deterministic field parser that understands the authored answer convention. Blank-question and blank-card controls expose input dependence. Require 80% exact complete answers in both phrasings, 65% all-eight cards, a 50-percentage-point advantage over deranged supervision and 80% complete correct responses after payload relocation. A pass supports learning the pictured record task and motivates removing a layout or lexical cue. A failure will be localized to field selection, writing or stopping before increasing model size. Independent free translation, unseen writing systems and whole-system efficiency remain separate requirements.
