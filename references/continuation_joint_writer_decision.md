The next bounded model change replaces the deterministic thresholded marginal
writer with a normalized autoregressive distribution over each full glyph.
Keep the actual final visual prompt reader, all continuation residuals, learned
query, image-feedback encoder, affine statistics and stop head frozen. This
preserves a measured conditional QA capability rather than constructing another

step is not the compact-model or efficiency result required by the full goal.

For a complete 32-by-32 binary image Y, partition pixels losslessly into 128
physical 2-by-4 masks r_j. The writer learns

    p_phi(Y | h) = product_j p_phi(r_j | h, r_0,...,r_{j-1}).

Each categorical output enumerates the 256 possible eight-bit masks. It is not
a Unicode or glyph inventory. All 2^1024 images remain representable. Earlier
physical pieces provide within-image dependence; no future target piece enters
its predictor. Runtime writes every bit with this neural head, then the unchanged
image encoder rereads the emitted image. There is no lexical decoder, font,
retrieval bank or teacher in this path. A discrete physical output variable does
not imply that every representation or computation is continuous.

This distribution avoids identifying thresholded independent pixel marginals
with a supported complete-image choice. It does not guarantee a valid character,
semantic selection or a coherent next sentence. The mathematical factorization
is established, not a new theorem. Greedy physical decoding remains capable of
wrong sequences. The intended contribution must be measured complete-language
behavior of the integrated image system.
