# Following a new question on the same page

The last small reader returned identical answers to two distinct English questions on 164/226 Chinese novel passages. For Chinese questions it returned a strip outside both annotated names in 316/452 replies. This comparison tests whether bilingual supervision about which action a question describes improves autonomous selection without changing the deployed model.

Before training or scoring any new answers, fix 28 manually selected excerpts from the classical Chinese text of Liu Yiqing's *A New Account of Tales of the World*. Use the classical source supplied in the neighbouring ZhJpBook project. The edition is identified by its complete SHA-256 in the preparation script. Each excerpt has two separately written traditional Chinese questions, their English counterparts, and two different source answers. Both people appear in the passage. Swap their complete written names simultaneously to create a second, counterfactual page. Keep the questions fixed. Each passage has eight replies across both pages, languages and questions. The unit of analysis is the original excerpt. These passages will never enter this fit. Exact answer scoring requires the specified source expression and can miss aliases. The original putative events are historical anecdotes. The edited pages are experimental constructions. Selection is purposeful and the questions are project-authored. [Primary text](https://www.gutenberg.org/ebooks/24047) · [Fixed questions and source excerpts](evidence/role_question_binding_20261124/classical.tsv)

Use real bilingual BiPaR training question pairs from the four original training works. Add two supporting excerpts on one page by pairing distinct natural who-questions with different source answers. Locate a unique reference image on each source page, retain its complete local clause and at most one adjacent sentence on either side, and exclude questions or source excerpts that contain the rival answer. Vary support order during training. Preserve provenance and test split exclusions. Both fits start from the released 64,666-parameter reader. Both minimize the same unrestricted negative log probability of all source intervals that produce the human answer. Give both arms the same bilingual image pairs, update count and warm start. In the experimental arm add a symmetric two-choice contrastive loss between the Chinese and English representations of the two questions about each page. Corresponding questions are positives and the other question on that same page is the negative. Compute the same similarities in the control with zero auxiliary weight. Use pooled query features already consumed by the reader. No new inference parameters or teacher calls. Run 12 passes, batch size 12 pairs, cosine AdamW starting at 0.00035, weight 0.5 for the auxiliary loss and cosine temperature 0.1. Limit each fit to 20 minutes, 8 GiB allocated VRAM and one 4090 D.

On the fresh classical set report individual name images, both questions correct for each page, and all four correct across the name exchange for each language. Compare unchanged reader, human-only fine-tune, aligned fine-tune and the aligned checkpoint with a fixed pictured who-question in each language. Both the alignment-minus-human and alignment-minus-unchanged lower 95% paired bootstrap bounds on complete four-answer comparisons must be positive in a language to support a transfer claim there. Repeat the ordinary two-book diagnostic unchanged and report open exact answers and complete pairs per language. Check a training slice to distinguish poor fitting from transfer failure. Score all final weights once; do not choose checkpoints, modify the test questions, or select examples to alter a result. If transfer fails, use saved output comparisons to distinguish candidate location, confusion of the two names and question insensitivity.
