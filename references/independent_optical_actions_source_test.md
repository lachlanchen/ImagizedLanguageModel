# Does the pictured source change the probability of its translation?

This secondary test was specified during training, before free generation or inspection of any new model predictions. It uses the four frozen books and never changes the primary complete-answer criterion. Within each book and direction, sort the 24 requests by source glyph count, then original position. Match adjacent requests into 12 disjoint pairs. For each pair compute the summed log likelihood of assigning both pictured targets to their real sources and to the exchanged sources. Both assignments use the same target strings and include their respective learned stop actions. Pure target-frequency preference cancels. Compare strict assignment wins with chance (one half) and with assigning longer answers to longer sources. Report ties and all per-pair margins. Cases with equal source lengths control the length cue directly. Report the actual independent sample of books.

The single-cell parse is unique. For the strip model rebuild the training-only pair-merger and verify its canonical action sequence on every training target against the archived labels before scoring held images. Assignment uses supplied target histories and two choices. Free writing is evaluated separately under the original registration.
