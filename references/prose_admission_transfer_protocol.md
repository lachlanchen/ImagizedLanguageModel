# Historic admission-price questions outside the dialogue collection

Keep both segment readers and all decoding fixed. In the official Search and Zhidao development subsets of DuReader 2.0, include every question containing 门票 about a named tourist attraction. Exclude the 2018 World Cup event. The ten retained questions include one disputed price and questions with season, group and discount conditions. This is an archival reading test; the prices describe the upstream documents.

Use the original question, a supplied attraction name and a single 160-cell excerpt of an upstream selected document. Rank all excerpts using the ticket or price cue, character bigram overlap with the question and whether the named attraction occurs. Use original order for score ties. Excerpt selection receives no reference answer or expected numeric value. Report how many selected excerpts contain at least one recorded plausible base price before measuring the model. An emitted core base amount can be compatible while discounts, dates and alternative conditions are missing. Count a stricter response separately for the unambiguous single-amount cases and disclose contradictory labels. Release source identifiers, selected locations, hashes, predicted strings and scoring metadata. Reproduce source pixels locally from the upstream archive for research. Earlier project work used DuReader; the fitted CrossWOZ systems have no trained DuReader component.
