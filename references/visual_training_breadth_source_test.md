# Does the visual source change what the decoder predicts?

For each of the 96 fresh translations, compare the probability of the actual reference glyphs including stop under two sources, leaving the target history and original draft identical. Use the prespecified same-direction donor from a different book. Repeat with only the draft exchanged. Record source and draft effects at each reference position, correct-to-wrong and wrong-to-correct changes, the number of requests with positive mean log-probability advantage for the true source, and which reference and actual free answer the intact model prefers per glyph. Run this after the final weights are fixed on CPU. This intervention tests conditional dependence on the pictured source while controlling the target history. It cannot establish successful free writing. If most sources help but coherent answers remain rare, inspect supervision and the conditional distribution of competing completions before changing the renderer.

Also compute the difference between the length-normalized log scores of the supplied reference and the actual free answer at all four combinations of true/donor source and true/donor draft. Attribute the change from both exchanged to both intact by averaging each channel's contribution over the two orders of restoration. The two contributions sum exactly to the change in preference. Report how often the intact model ranks the reference above its own output. Scores compare canonical spellings and cannot distinguish paraphrases on their own.
