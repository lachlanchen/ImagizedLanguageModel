# How much of the question reaches the writer?

A generator that retains only the last two glyph signatures cannot distinguish any of the 1,788 formatted questions in the earlier Chinese passage-reading test. Each original prompt ends with 答：. The most frequent complete reference image occurs six times. Even an ideal predictor given only this state could get at most **6/1,788** exact complete answers on that cohort. Removing the common answer cue exposes more of the question, but keeping only its last two visual signatures still permits at most **184/1,788**. These are empirical capacity ceilings. No model was fitted or asked for a new answer in this calculation. [Recount](evidence/shared_layout_writing_20261118/question_suffix_ceiling.json) · [Earlier passage-reading experiment](visual_extractive_reading_result.md)

Let $s_i$ be the state the writer receives and $y_i$ the bytes of the complete reference image sequence. If a set of questions has the same state, any deterministic decoder gives that set one answer. Writing $n(s,y)$ for the observed counts gives the sharp upper bound for a lookup function with unrestricted output capacity,

$$\mathrm{accuracy}\ \leq\ \frac{1}{N}\sum_s\max_y n(s,y).$$

A stochastic decoder with fresh noise independent of the original question obeys the same bound in expectation. In each state, its expected number correct is a weighted average of the observed answer counts. The result applies to exact agreement with the supplied images. It does not score paraphrases. For the raw questions, 1,716 examples belong to states associated with several different answers. Supplying a unique passage identity in addition to the raw question suffix raises the empirical ceiling to 1,609. A passage identifier is privileged information in that calculation. A unique full question and passage state can distinguish all 1,788 examples; uniqueness alone measures no predictive skill.

## A model that preserves the necessary information

Maintain an ordered memory of pictured prompt cells. An encoder can store one key and value per imaged cell, including a position embedding. At each writing step, the current state attends to that memory and to already written glyphs. Two questions ending in 答： still have different earlier memory entries. Permuting two pictured glyphs changes their position-dependent keys. Summing all glyph images into a single ink overlay would instead give the same sum for 我爱人 and 人爱我. This is the information loss familiar from coarse-graining in physics. A prior can suggest a likely order; it cannot identify which sequence produced that sum without additional observations. [Attention mechanism](https://arxiv.org/abs/1706.03762) · [Ordered glyph volumes](ordered_glyph_volume_research.md)

Keep a shared layout $Z$ for coordinated strokes and let the memory also predict fine detail $R$. For binary glyphs, fix a coarse reconstruction $U(Z)$ and define $R=X\mathbin{\mathrm{xor}}U(Z)$. Then $X=R\mathbin{\mathrm{xor}}U(Z)$ exactly, including an unseen handwritten form. The identity proves representational capacity. Learning the distribution of $R$ given the question, written history and $Z$ is the prediction problem. Score the joint conditional likelihood of layout and residual. Learn a separate end event from complete sequences. Compute the expensive language state once per glyph and let a smaller local network handle its spatial detail. Numerical speed and useful answer quality both require measurement. [Coarse-to-fine image prediction](https://arxiv.org/abs/2404.02905) · [Prior pixel-language generation](https://aclanthology.org/2024.findings-acl.874/)

The new physical writer supplies the direct control. In its greedy mode the only input to fine detail is the chosen layout, leaving 426 of 668 observed successors outside its entire range. Replacing the count estimator with a larger transformer while keeping that writer can change which reachable image is selected. It cannot add a missing image to the range. Conversely, a lossless physical renderer with the two-glyph question state still inherits the six-answer ceiling on the formatted questions. Existing full-context trials also show that giving a model access to history does not ensure that it learns to use it. [Physical range measurement](shared_layout_writing_result.md) · [Earlier full-context trial](trainable_visual_context_result_20261117.md)

A meaningful test holds the writer fixed while exchanging two different questions about the same passage with identical endings, then holds the reader fixed while supplying true or predicted fine detail. Use fresh passage groups and retain complete answers, blanks, wrong glyphs, stopping and free continuations. Success requires questions to change the answer correctly and predicted detail to preserve readable writing. Report whole-system time to a common answer-quality threshold before estimating a speedup.
