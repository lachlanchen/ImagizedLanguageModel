# Does retaining a span's emission phase improve the next visual decision?

In 90 naturally stopped optical translations, 195 of 1,064 emitted spans had several native embedding addresses after pooling phases. All 1,064 had a unique address within their actual initial or continuation phase. Freeze the source reader, output candidates, source state, ink motor, stop and greedy selection. Change only the feedback embedding for ambiguous pictured spans to its frequency-weighted value within the observed phase. Use separate initial aliases for visible surfaces shared with conflicting continuation keys; their ink must remain byte-identical. Test an alias-only control with the original embeddings against all 96 archived outputs. Preserve any resulting differences. Compare the phase-conditioned optical outputs, parent optical outputs, native text, independent broad outputs, stored Qwen translations, references and foils in two new grading orders. Replay a fixed CPU subset. This intervention uses a panel that identified the ambiguity, so any improvement needs confirmation on fresh works. Consider it promising only if complete meaning gains exceed losses, the paired lower work bound exceeds zero and natural stops are retained. Otherwise distinguish increased local faithfulness from autonomous translation and keep the parent.
