# Writing an answer from a pictured question across typefaces

The two-signature writer has an empirical ceiling of 6/1,788 formatted answers and can draw only 539 distinct greedy images. Test a bounded grounded form of writing with the existing trained full-question passage reader. Freeze its start, end and length estimates. The new experiment compares two image writers with that same reader on every input. Both must produce a complete Serif answer from Sans images. One receives the selected glyph's 4-by-4 coarse ink layout alone. The second also receives the local source ink surrounding each output patch. This tests whether persistent access to the question and fine source detail can jointly yield complete, question-dependent writing. The reader selects a span. The experiment does not establish free answers outside that span or feedback-based book continuation.

Train the writer on glyph pairs from the original 2,127 CMRC training passages verified against the source raster hashes. Fit one frequency-weighted pass using Noto Sans CJK Regular and Noto Serif CJK Regular, face 2, nominal size 26, the same baseline and 32-pixel square. Reserve every distinct source bitmap whose SHA-256 digest reduced modulo ten equals zero as a transfer probe. Exclude every occurrence of those shapes from writer fitting. Record any source-to-target aliases, exact reconstruction, ink F1 and copy fidelity on all trained and all withheld nonempty pairs. No answer font or lexical labels enter the deployed writer. Learn the most frequent 4-by-4 target ink patch at each position. Condition on the source layout, and in the detail arm successively on central 4-by-4 and surrounding 8-by-8 source neighbourhoods. Include position-specific local-only fallback for unseen layout/neighbourhood combinations. A shared source patch and layout can lead to different target patches; report that limitation.

For the language test use all eligible questions from the original official CMRC development file, including every supplied reference. Exclude titles and normalized passages overlapping the original training file, duplicate question/passage pairs, empty or unsupported inputs and empty or unsupported reference sets; report all counts. Keep the original question ID for audit only. Both arms use the frozen reader on the same Sans images. At scoring, render every accepted human reference in Serif and count an output once if it matches any complete reference exactly. Record source-span exactness in Sans, output that is byte-identical to a copied span, conditional image fidelity for correctly selected spans and overlap for held-out source shapes. Report control outputs for a blank question, an erased passage and a cyclically exchanged question about the same passage. Each raw question carries the same visible answer cue at the interface; remove that constant delimiter before the fixed reader, retaining the actual question. Equal input suffixes are evaluated explicitly. Controls keep their input lengths. Full free generation and independent confirmation on DRCD remain separate.

The grounded criterion requires at least ten complete exact Serif responses whose pixels differ from a direct source copy, a positive 95% whole-passage bootstrap lower bound for detailed minus coarse complete exactness and for normal minus exchanged detailed answers (10,000 draws, seed 20261123). Count both questions correct for cyclic pairs requiring distinct reference strings. Preserve actual pictures from the first eligible successful pair and first complete failure, plus all raw output cells and question identities. Publish free-form and transfer limitations. If the coarse writer already suffices or the detailed route fails the comparisons, retire the claim of improved question-conditioned writing. Train and evaluate serially on at most two CPU threads with 4 GiB RSS, at least 24 GiB available host RAM and a 25-minute ceiling. The registered GPU generation proceeds independently.
