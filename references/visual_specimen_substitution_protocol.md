# Substitution of unnamed specimens inside a translation

The fitted pointer copied an unfamiliar shape once in 106 of 140 translations but changing that shape left the rest of the answer stable on only 5 of 70 pairs. For the specific request to carry an opaque specimen through a translation, its identity should determine the pixels at its destination while its appearance should leave the grammar invariant. An instruction to interpret the meaning of the specimen requires its appearance.

Freeze the trained pointer. In a separate specimen-preservation mode index distinct out-of-training-palette cells in order of first occurrence. Use the average optical descriptor of the 1,024 training specimens for each such slot and retain its exact original pixels for output. Infer a complete sequence of palette or slot actions; substitute the actual pixels after stopping. Use exactly the same weights with original optical features as the comparison. Reserve every eligible aligned Tom/Mary pair in the original development split for a confirmation of the mechanism (these sentences previously selected the base checkpoint by likelihood; the substitution outcomes have not been evaluated). Use the original image pairs and two fixed unseen substitutions per sentence in the test split to compare with the preceding report. Include failed and duplicated outputs. Compare once-only stopped transport, equal surrounding output under a swap, exact complete sentences and surrounding chrF. Inspect all fifteen or more eligible pairs per direction if present. Run a CPU forward pass per request with and without cross-request reuse; verify every output byte, stopped flag and actual neural-call count. Report warmed wall time separately. The cache is local to one frozen model, direction and canonical pictured source. This mode is inappropriate when the meaning of the image itself is requested. Stop if exact equivalence fails. Keep the original optical mode available whatever the result.
