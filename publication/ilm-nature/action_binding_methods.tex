\paragraph{Binding one pictured question to one participant.}
For each passage version we presented each action question separately. We scored the complete stopped image of either participant's name and separately generated an answer without supplying the names as candidates. If $D_{wa}$ is the log probability of the first name less that of the second on world $w$ and action $a$, the required signs are positive, negative, negative and positive in row-major order. A score of the form $D_{wa}=P_w+Q_a$ cannot have all four signs. We decomposed the measured table into its mean, page, question and interaction terms, using the four orthogonal sign patterns on two binary variables. Lean~4 verifies the sign obstruction, exact reconstruction in common integer units, and the condition on the interaction for all four signs to be correct. The interaction measures whether the question changes the effect of editing the page.

\paragraph{Learning to write individual clauses.}
Two fits started from the same 87.1-million-parameter writer trained on edited credits and stories. Both received all 2,788 original edited training scenes. For each scene, page version, question language and requested action, the writer saw the same pictured prompt twice. Both exposures named the supported participant in the aligned fit. In the control, one exposure assigned the other participant to the same predicate. The fits shared paired-question replay and familiar historical images. For book passages, we used the human questions and annotated answer spans from BiPaR. A local Qwen3-4B teacher proposed Chinese clauses containing the annotated answer for each of two different questions. We checked that the other answer was absent, the clause added Chinese wording and the target could be produced from the available print bank and source page. The same surviving book clauses were used for both fits. A model-based reader checked 16 teacher-accepted pairs selected by a fixed hash order. Thirty of 32 clauses were supported. One repeated a mistaken name in the question and one reversed a speaker's explicitly stated belief.

At inference we passed the same image of a passage with each question in turn, batching the two computations. The writer chose every output cell and a separate stop for each clause, with up to 48 cells per clause. Concatenation preserved the supplied question order. We also evaluated the ordinary joint prompt, which permits 48 cells for the whole answer. The aligned and independent-label writers and their common parent used identical limits within each route. For the individual-clause metric each response had to stop, include the requested fact and omit the other fact. Success for an edited scene required four responses within a language. Unedited novel passages required two. A strict name match or an edited-scene contrast can still receive credit when accompanying prose is inaccurate.

We reserved twelve additional paired stories before either fit, covering direct actions, changed plans and corrections to reported events. The earlier twelve stories and held-out credits remained diagnostic. We separately evaluated 96 previously reported novel passages and another 253 eligible passages from the validation split. The complete-clause reading used one order, fixed by story index, for both page versions and both question languages. A single model-based reader graded stopped responses with system identities hidden, allowing supported paraphrases in the requested order. The reader knew the study design. We compared the parent in both modes, both new fits in the separate-clause mode and a local text Qwen3-8B. Device energy came from the GPU's cumulative hardware energy counter; it excludes host energy. Warm request measurements used one pair of questions at a time, after model initialization, with passage and question images prepared in advance.
