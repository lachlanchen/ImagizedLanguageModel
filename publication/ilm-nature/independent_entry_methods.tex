\subsection*{Candidate-conditioned updates and independent prompts}
Both writers started from the final ordered-reader weights. For candidate key $k$ and question residual $r$, the shared writer uses $k+(1+g)r$. The candidate-specific writer uses $k+[1+g\tanh(k)]\odot r$, with elementwise operations and a scalar $g$ initialized to zero. The updates coincide initially. When two fields share an anchor and recurrent state, their common additive question update cancels from their relative score. The candidate-dependent gain can distinguish their updates. Its larger representational capacity did not improve the complete-answer measure in this comparison.

Each fit ran eight passes over 89,200 pictured questions per epoch. These included the preceding 44,600 requests, 35,680 questions crossing additional phrasings and aliases with the original answer images, and 8,920 examples with a status before the field. Both arms used matched AdamW updates, 128 requests per batch and one RTX 4090 D. Training and checkpoint writing took 30.30 and 30.60 seconds for the shared and candidate-specific fits. Shared input preparation took 6.41 seconds. These fit times exclude earlier training, rendering, independent question authorship and evaluation. A post hoc replay control repeated each original question exactly twice per epoch. Each second presentation replaced one of the new wordings with the same target bitmap at the same batch position. The initial state, optimizer, recurrent history and number of updates matched the shared-update fit.

For the independent set, four distinct cards were sampled for each of six stage combinations. Four separate calls to local Qwen3-8B per selected headword commissioned the two factual requests crossed with the two supported historical stages. The four ambiguous questions related the meaning specifically to an inscription or asked how the inscription expressed it. They remain in the primary denominator. The other evaluations used fixed constructions and all 284 held-out families. The two original question layouts stayed within two exact answers of their previous count for the shared writer, including all 1,136 simple questions. All scores require an autonomous stop and equality of every target pixel.

A separate corpus for subsequent passage reading pairs human-written CMRC questions about one passage. Reversing their order preserves all question glyphs and exchanges the required answer spans. A semicolon separates the two target spans. The original internal passage split gives 24,846 ordered training requests and 6,086 development requests. Only two complete development targets appear as a single contiguous passage span. Joining two saved answers from the earlier passage reader with the true question split reproduces 440 targets. This is a supplied-segmentation comparison. A reader that takes the combined prompt and emits both answers remains to be tested.
