\section*{Eight identical final glyphs}
We paired held book windows from the same work whose 32-cell prefixes end in the same eight glyphs but precede different attested words. Each window occurs in at most one pair. An order-five predictor assigns each proposed word the same probability under both prefixes. Across 256 pairs the intact model shifted the odds towards both observed word--context associations in 137, compared with 128 for the shuffled model (paired interval for the difference $-2.7$ to $9.4$ percentage points). Only one intact pair ranked both observed words above their rival. Greedy writing recovered 22 of 512 individual next words and zero complete pairs. Other continuations can be valid. These counts measure sensitivity to the recorded context and cannot determine whether every alternative was meaningful.
An offline assessor given both word choices in both orders identified both attested words in 52/256 pairs from the short prefixes and 81/256 when supplied up to 96 preceding cells. The judge had no access to subsequent words.
