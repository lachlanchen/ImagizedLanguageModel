\paragraph{A pictured transducer with latent edit alignment.}
Both writers use a common pictured source encoder and a recurrent history determined by the emitted physical code sequence. The joint state at source position $i$ and after $j$ outputs is $\tanh(m_i+h_j)$. Copy and replacement advance both indices, deletion advances $i$, and insertion advances $j$. Stop is legal at source end. The physical drawing probability factors over twelve successive groups of four measured ink bits. The renderer writes those bits into their measured coordinates in the final image, so reading a copy or a free drawing supplies the same feedback given the same code. The learning objective concerns these physical codes; evaluation compares all 1,024 bitmap pixels.

For incoming deletion, insertion and diagonal edge probabilities $d,t,r$, the probability mass arriving at a lattice cell obeys
\[
 A_{ij}=A_{i-1,j}d_{i-1,j}+A_{i,j-1}t_{i,j-1}+A_{i-1,j-1}r_{i-1,j-1}.
\]
The diagonal combines replacement and compatible copy mass. We multiply the final mass by the stop probability. A row-wise cumulative log-sum-exp evaluates the variable-length target in double precision. Both arms score the same neural grid. One maximizes a single minimum-edit path and the other its marginal over compatible paths. Each receives three passes over 16,384 real training pairs (source up to 24 cells, modern target up to 32), plus 4,096 quote examples per pass. We update 568,373 of 1,984,053 parameters, freezing the physical renderer. Test sentences allow up to 96 classical cells and unrestricted modern reference length. The two 1,024-request cohorts have disjoint training-excluded chapter pools and contain previously unused source strings and bitmaps.

For next-image decoding we close the cursor distribution under deletion, enumerate copy and free-drawing mass by measured ink prefix, retain four prefixes at each within-glyph step and compare a completed code with stopping. The highest discarded prefix mass bounds every descendant. We check normalization and the probability of a stopped output using the independent training lattice. Minimum-risk decoding draws 32 paths per source. Sixteen supply proposed output strings and a per-cursor span consensus. The other sixteen estimate each candidate's expected unnormalized bitmap edit distance. Selection can also return either deterministic decoding. We retain each sampled stop, cursor and physical output. A consensus has a constructed ending. Exact recorded sentences, corpus edit distances, and uncertainty over chapter resamples remain separate measurements.

For the source-order test we exchange naturally inserted phrases of equal length from different chapters, with matching immediately preceding and following modern glyphs. Neither source contains any exchanged glyph. Each sentence appears in at most one pair per cohort. We compare the joint log probabilities of both assignments with the original and reversed classical sources. The follow-up ends observation immediately after the exchanged phrase, summing cursor mass there. It supplies no subsequent modern writing. Intervals for this conditional comparison resample sentence pairs and describe the observed cohorts.
