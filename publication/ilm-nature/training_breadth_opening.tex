\noindent Both 1.82-million-parameter writers received 11.30 million supervised glyph decisions. One saw 147,456 distinct bilingual pairs and the other saw 24,576 pairs six times. Byte-level tracing found 1,032 and 185 constructed event pairs, respectively, within those sets. A separate control component added the same 6,240 supervised pairs to both arms in every pass. On four new books the broad, repeated and starting writers earned six, four and five complete-meaning credits out of 96. The broad writer retained both polarities on 226 of 236 controlled pairs.

\section*{Reading and writing ink}
The writer receives aligned $32\times32$ printed cells and a rough translation computed from the same input by bilingual phrase tables. It learns to emit a glyph or copy it from the draft, then feeds back the selected shape. The learned stop sets the output length. The motor uses a finite repertoire of printed forms. Both fits used the same initial weights, supervised cell counts and optimizer steps on one RTX 4090 D.
