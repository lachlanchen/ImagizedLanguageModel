\newcommand{\PaperTitle}{Learning conditional language\\in continuous image space}
\newcommand{\PaperSummary}{Written language includes forms that cannot be faithfully represented by a fixed character inventory. We study language modelling with visible writing as both the input and generated output, using continuous internal states and a single consumer GPU. A causal reader trained on Chinese raster streams ranks the next glyph at 19.97\% top-1 on 2,048 development windows, compared with 12.26\% for a bigram control and 18.36\% after shuffling earlier history. Realizing that predictive information as readable output remains difficult. A separately trained glyph diffusion prior and noisy visual critic retain 21.88\% completed-image ranking, yet recover only one of 256 target identities after four-sample selection. We therefore test a directly conditional four-glyph velocity denoiser with 22.18 million total parameters. Its single-GPU run completes 8,000 updates in \TrainSeconds\ seconds. Direct first-position identity is \FirstIdentity\%, and block-mean identity is \BlockIdentity\%, with an ordered-minus-shuffled gain of \BlockGain\ percentage points. These measurements separate visual prediction, glyph synthesis and conditional language generation, and define the remaining requirements for an independent model that learns and writes language through images.}
