\noindent\textbf{Can a visual writer preserve meaning by translating each span of a pictured sentence exactly once? We learned bilingual phrases from 497,775 aligned sentence images and generated translations with explicit source coverage. On passages from four unseen books, the phrase writer reproduced 445 of 1,464 distinct reference strips, compared with 280 for the ordered alignment writer. Repeated triples occurred in four phrase answers and 28 ordered answers. The phrase writer received zero complete-meaning credits on 96 requests. A neural visual writer earned one and a quantized text model earned 90. Exhaustive search found that none of the 96 reference images could be composed from the permitted phrase choices.}\par
\begin{multicols}{2}
\section*{Translating a span of ink}
We aligned visual strips in both directions on one RTX 4090 D. Consistent source and target spans yielded 7.24 million phrase occurrences. We retained pairs observed at least twice. The decoder tracks covered input positions and emits a learned sequence of target strips for each chosen span. A target bigram model scores the joins between phrases. This adapts statistical phrase translation to a fixed inventory of printed glyph images.\cite{koehn}
\end{multicols}

\section*{Meaning in new passages}
Each of four books contributed twelve passage pairs in both directions. A bilingual model evaluated each answer twice against the source. It credited 73 supplied references and zero unrelated foils. In a separate editing comparison, Qwen recovered four complete meanings from the phrase drafts alone and 73 when it also saw the source. Its original source-only answers earned 86 under the same grading pass.
\section*{What coverage guarantees}
All 568 recorded phrase paths consumed every source position exactly once. Only 953 of the 1,464 distinct reference strips appeared among the available target options, counted by request. A different wording can still convey the same meaning. On a separate subset of 96 controlled events, the semantic judge credited two phrase answers, 50 neural answers and 56 references. An unrestricted writer would need to learn when to reuse the available phrases and when to compose other glyphs. \repo{references/covered_phrases_result.md}{Results, raw images and code}.
