\paragraph{Scoring pictured sections.}
Each packed $32\times32$ glyph was mean-pooled to $16\times16$. We projected its intensities to 96 features and added a width-three contextual convolution. Each question position scored the most similar paragraph position by normalized inner product. A learned weighted mean of these scores was combined with four exact contiguous-match features for runs of one to four glyphs. Batch-local integer addresses shared identical input pixels. We trained 61,925 parameters by two-way cross-entropy for five epochs on 14,446 paragraph assignments (16.4 seconds of optimization, 110.1 MiB peak allocated). The absolute times exclude data preparation and all inherited weights. For human questions we split at the central eligible sentence boundary, then required an accepted reference on exactly one side. The learned selector and literal control received the same explicit boundaries. The literal control broke longest-run ties by total matched glyphs.

For a fixed writer, let $S$ denote correct selection and $W$ the event that supplying the annotated paragraph yields an accepted response. The routed error event is contained in $S^c\cup W^c$. We proved the corresponding finite error-count bound in Lean and recounted the image bytes and stop bits under both source choices. For quantized comparison scores $a,b$ (annotated and rival), ties counted as errors satisfy $\mathbf{1}_{a\leq b}\leq\max(0,1+b-a)$. A score perturbation of at most $\epsilon$ per candidate preserves selection for $a-b>2\epsilon$. These deterministic results identify remaining writer error without assuming independent selection and generation.
