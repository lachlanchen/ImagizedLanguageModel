\paragraph{Choosing between a source span and missing writing.}
A 61,972-parameter neural reader learned when to return visible ink, where to start and where to end. It shared an interface with the frozen 2,115,971-parameter expression writer. On 1,788 held-out passage questions it returned 434 complete reference images, compared with 269 for the earlier extractive reader (paired passage-bootstrap 95\% interval for the difference, 7.38--11.15 percentage points). Of 1,108 answers longer than eight cells, 164 were exact. Exchanging questions within passages left five exact answers on 1,783 eligible questions.

On the official CMRC development set, the standalone model returned an accepted reference for 1,000 of 3,219 questions, including 913 first-reference matches. The input typeface could render 3,170 questions in 836 passages. The previous reader solved 565 on the same renderable set (paired difference, 12.08--15.45 percentage points). Of 3,100 different-answer pairs, both answers were exact for 316. The first successful pair asks for a railway's length and its operator (Fig.~\ref{fig:mixed-ink}a). The first failure contains the company names and extra ink (Fig.~\ref{fig:mixed-ink}d).

On 17,600 separately held-out gap windows the frozen writer recovered 441 missing expressions, including 330 of 12,990 with all four answer glyphs absent from the source. Local counts recovered 989. With unfamiliar instruction wording, 398 of 16,089 eligible windows had all three requests answered correctly (Fig.~\ref{fig:mixed-ink}c). On the earlier 17,686 windows an initial numerical replay changed 189 stopped streams. Restoring the archived matrix-multiplication precision reproduced every output byte, length and stop. Source quotation improved on natural questions. Most missing expressions still exceeded the writer's language capability.

The two output paths impose a testable limit on book continuation. Given a preceding segment $P$, an exact next segment $Y$ longer than eight glyphs must already occur contiguously in $P$. On the two previously held-out Chinese book titles, 53,585 of 53,711 adjacent segment pairs could be rendered. For 47,944 pairs (89.5\%), neither path could emit the recorded continuation, even with perfect parameter estimation. Of these, 47,943 required at least one glyph absent from the preceding segment. The bound concerns reproduction of the recorded continuation. Other linguistically valid continuations remain possible.
