\paragraph{Phrase coverage and visual history.}
We expressed the fitted 55,872-pair composer as an acyclic graph whose vertices are positions in the classical source and whose edges emit visual phrases. Hypotheses at each vertex with the same last emitted image share all future join scores. Keeping the six best distinct prefixes per such state gives the six best distinct complete streams under maximum path score. For a separate reference-informed bound we propagated a row of minimum edit costs for every reference prefix along each edge. Taking the minimum in each column at the destination and recording predecessors gives an attaining stream. A second exact prefix-membership algorithm verified zero-distance reachability. Both computations allow every edge of the fixed composer. They measure support for one physical gloss and depend on its alignment.

We sampled 1,024 classical passages of 5--24 cells with reference lengths of 3--48, capped at eight per chapter. Each subsequent evaluation excluded chapters from fitting and earlier evaluation cohorts. The coverage study used the archive's calibration partition. Separate readings used six chapters in each of three priority strata marked by characters associated with negation, speech or events. These markers are imperfect, including calendrical uses. Identical answers shared a grade. One study-involved model reader saw the streams transcribed through their observed canonical forms in randomized order. Grades were frozen before scoring against the assignments. These small readings do not estimate population-wide acceptability.

The writer embeds pooled ink and 48 physical landmarks per cell. A bidirectional recurrent encoder reads the source. A causal recurrent decoder embeds the previous emitted bitmap, attends to visible source positions with a learned increasing centre, and chooses among copying a source image, selecting one of the 2,048 most frequent training exemplars, drawing four-pixel landmark groups with a frozen ink motor, and ending. Training combines cross-entropy for emission routes, supervised source attention and active image selectors with a smooth alignment penalty. Evaluation starts with an empty output and caps each sequence at 96 images. The initial writer made 8,503 physical copies and 18,936 exemplar selections on intact sources. The open drawing route was never chosen. The eight-pass fit took 4,736 updates and 93.4 seconds on one RTX 4090 D, with 836,245 trainable parameters and 349 MiB peak allocated tensor memory. The figures exclude corpus preparation and prior ink-motor training.

For the single-error intervention we held source, position and all other previous images fixed. There were 341 lost and 32 gained correct following images. One pre-divergence image disagreed between batched and stepwise replay, which we retained. For the matched training test we recorded the parent's clean-history choices on 1,762,187 training positions. At each pass we independently replaced one-third of eligible erroneous predictions in the experimental history, retaining clean targets. Both continuations used the same fresh optimizer, schedule, shuffled rows and 2,368 updates. Fitting took 43.0 and 42.6 seconds, respectively. The shared run peaked at 419 MiB allocated on device. The new test contained 724 chapters. Edit error includes insertions and can exceed 100\%. Exact changed glosses count only targets different from literal source copying. Time and memory are measurements of these fits and do not compare computation at matched language quality.
