\paragraph{Classical--modern visual editing.}
We used NiuTrans/Classical-Modern (revision \texttt{4e746ea}), a collection of classical sources and modern translations aligned automatically at sentence level. We partitioned chapters by hash and deduplicated source bitmaps across partitions. Training included 48,000 pairs from 4,882 chapters, comprising 1,053,492 source cells and 1,563,174 target cells. Evaluation retained 2,048 requests per roster, including four and three requests outside font coverage, respectively. The writer takes a separately pictured question and sentence on aligned 32-pixel cells. Training mixed two phrasings each for quotation and translation. A convolutional source encoder conditions a causal recurrent editor on the cursor, the previous action and previously emitted pixels. Operations copy, replace, insert, drop or stop. Drawing predicts twelve successive four-bit measurements and decodes these into a full bitmap. Supervision follows a minimum-edit alignment. At inference the model receives neither that alignment nor reference writing. The independent bitmap recount checks saved streams, lengths, stops, and the copy and draw operations for each exact longer mixed output.

The initial fit used 3,840 updates in eight passes of 60,000 presentations. Its 1,984,053 parameters included 568,373 trainable editor parameters. It took 38.6\,s with 469\,MiB peak allocated GPU memory on one RTX 4090 D. Separate training of the frozen-language renderer took 8.0\,s. A further 42,184 parameters predicted a finite insertion allowance at each cursor from training edits in 9.6\,s. Training timings exclude corpus preparation and evaluation. The fixed control allowed five insertions per cursor. A second decoder added the log probability of the best retained twelve-group ink path to the log probability of drawing, with beam width four inside each glyph. Each variant used a 192-cell output limit. We counted unsupported requests in the denominator for complete translations. Edit rates divide total physical glyph edits by total renderable reference glyphs. Paired intervals resample chapters 2,000 times. The local control selects the most frequent output block for a training source neighbourhood, backing off to a single source cell with insufficient observations.
