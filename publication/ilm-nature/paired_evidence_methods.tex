\subsection*{Question-conditioned interval probability}
We prepared 219,711 human question--answer records from 35,019 fitting passages across CoQA, SQuAD, CMRC and DRCD. The held set comprised 64 new development passages from each source, with two distinct questions and distinct answers per passage. We excluded passages in the earlier assay and screened overlap using passage hashes and sampled 96-character fragments. The question-specific answer location did not determine the displayed passage boundary. The reader saw up to 600 source and 160 question cells. CoQA queries could include the preceding exchange. For 4,800 updates of 24 examples we alternated eight paired-question batches with two batches drawn from bilingual fiction, instructions and reference questions in each ten-update cycle. Each arm received the same 2,295,177 scheduled target positions. In 75,778 examples a human evidence range fell within the visible input.

An 80-dimensional encoder computed local convolutional features for both glyph streams. Attention and exact matches of one, two and three visible glyphs aligned source positions with the question. Following passage--question attention (\href{https://arxiv.org/abs/1611.01603}{Seo et al.}) and pointer--generation mixtures (\href{https://aclanthology.org/P17-1099/}{See et al.}), we assigned probability to a complete source interval $(i,\ell)$ of up to 48 cells. For source $s$, question $q$, answer $y$, interval distribution $a$, free writer $f$ and learned gate $\pi$, the model density for a stopped reply was
\[
 p(y\mid q,s)=\pi\sum_{i,\ell}a_{i\ell}\,
 {\bf1}\{s_{i:i+\ell}=y\}+(1-\pi)f(y,\mathrm{stop}\mid q,s).
\]
The sum includes every compatible occurrence. The free writer mixes recurrent and frozen causal glyph predictions at each step. Training minimized length-normalized negative log likelihood, using compatible prefixes when a target exceeded the training window. The auxiliary arm added $0.45$ times the cross-entropy of the evidence distribution against uniform mass on the visible human range. During decoding, the writer conditioned both the interval weights and the free path on each chosen glyph and stopped on its own end decision or at the 96-cell limit. The head has 325,111 parameters in addition to 2,117,313 in the frozen writer.

For finite paths with integer weights we verified in Lean that a single complete answer heavier than all competitors combined wins each greedy prefix decision including stopping. This is a sufficient condition on a learned distribution. It gives no convergence or efficiency guarantee. In a separate post-fit likelihood audit, 104 of 510 primary references had measured probability above one half. All 104 were written exactly in pixels with the correct stop. One SQuAD pair was unavailable for this probability audit. The free-writing evaluation retained all 512 questions.
