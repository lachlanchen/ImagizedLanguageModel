\subsection*{Two questions about the same pictured sentence}
We added a reading action that returns a complete run of source glyphs or passes the request to the existing writer. A learned decision between these actions allows a response to include glyphs or sequences absent from the source. An 88,019-parameter head read the frozen 694,152-parameter writer's question-aligned states. On 864 pairs of questions about the same sentence, matched training gave both complete answers in 100 pairs, compared with 72 when the additional paired targets were randomly exchanged, 58 for the frozen writer, and 73 for the separately trained passage reader (Fig.~\ref{fig:shared-sentence-writer}a). The matched gain over randomized supervision was 3.2 percentage points (95\% passage-bootstrap interval 1.2--5.4). Across all 3,505 complete DRCD passages the two fits answered 1,346 and 1,303 questions correctly. Each fit received 175,472 ordinary question presentations and 92,112 additional paired presentations in 3,136 updates on one RTX 4090 D. The matched fit took 140.3 seconds after inherited training.

The result was weaker on the 27 pairs asking for two distinct person answers. The matched model solved one pair and the randomized model solved none (difference 3.7 points, interval 0--12). A separate model-authored reading found explicit support for 23 of 54 requested relations in the selected sentences; only one pair stated both. For example, a sentence saying whom Wang Mang blamed also contains his name, but omits the earlier conscription event asked about in the first question. In the next pair the sentence identifies both the donor to MIT and the architect of the building. The writer recovered both names (Fig.~\ref{fig:shared-sentence-writer}c). On 24 newly authored scenes where both roles were explicit, we exchanged the two names and asked both questions in each order. The matched model gave 23 of 96 exact answers and no complete four-answer scenes. Local Qwen3-8B, given the passages as text, gave 90 of 96 answers and 20 complete scenes.

Learning the source-run action disrupted composition. On familiar requests for a reordered description the model went from 344 correct answers to zero of 404. We froze both the interval scores and the free writer, and trained only the 12,417 parameters deciding which action to take. After 640 updates that writer again gave 344/404 reordered descriptions and 30/32 descriptions involving two bronze names. It retained 148/387 person answers and 19/131 both-correct pairs with inference-time sentence selection. On the explicit role exchanges it gave 21/96 answers and zero complete scenes. Bringing back the ability to write a clause repaired the choice of output format. Following different relationships in an unfamiliar sentence remains difficult.
