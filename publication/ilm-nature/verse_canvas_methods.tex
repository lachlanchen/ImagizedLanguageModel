\subsection*{Conditional restoration of pictured verse}
We paired the two equal-length half-lines in each punctuated paragraph of the Tang anthology distributed by the Chinese Poetry project (revision b8594f81, \url{https://github.com/chinese-poetry/chinese-poetry}). We kept five- and seven-character pairs covered by both fitting fonts. We hashed author strings into 20 buckets, holding out one for an initial comparison and one for confirmation. We removed duplicate pairs and excluded either line if it occurred on either side in a preceding split, with fitting data processed first. Name variants can represent the same historical person. The model saw neither names nor titles.

The input consisted of the first line and a masked second line. Each $32\times32$ binary cell supplied 256 local ink densities. Two projections of width 192 combined aligned source and target cells with a position and metre embedding. Four bidirectional attention blocks predicted a distribution over 8,414 fitting bitmaps at each gap. We sampled a positive number of hidden cells per pair, with an additional one-quarter probability of hiding the entire line. The loss was cross entropy at missing cells. Inspired by conditional masked generation (Ghazvininejad et al., \url{https://aclanthology.org/D19-1633/}), the writer repeatedly committed the single most confident remaining glyph. A left-first control used the same weights. The byte comparator received four fixed byte slots at each cell boundary. Both modalities emitted canonical glyph images. These writers inherit the target length from the metre and use no learned stop.

Each fit used 10,000 batches of 96 pairs on one RTX 4090 D. The second comparison added half the mean visible-cell cross entropy to the writing loss. The additional term projected source and surviving target ink independently, applied parameter-free layer normalization and reused the output classifier. Training inputs, masks, font draws and parameters were matched across fits. For typeface transfer we also measured nearest-neighbour identification by cosine similarity to each fitting glyph in either fitting font. We resampled poet attributions 5,000 times for paired differences. The earlier within-volume test assigned two eight-cell endings by the sum of their conditional log likelihoods. Subtracting the exchanged sum cancels any additive passage-only or ending-only preference, as verified in Lean.
