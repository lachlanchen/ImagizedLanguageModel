\subsection*{Transfer of causal language prediction to pictured answers}
We used the twelve causal blocks of \href{https://huggingface.co/uer/gpt2-chinese-cluecorpussmall}{UER Chinese GPT-2}, pretrained on CLUECorpusSmall. Let $u(x)$ be the normalized 192-dimensional output of the earlier printed-glyph metric and $P$ its fixed random projection. We used $h(x)=\sqrt{2/D}\,\mathrm{ReLU}(u(x)P)$ with $D=12{,}288$. For the matrix $H$ of 7,902 distinct printed source rows and their native embeddings $E$, we set $W=H^{\mathsf T}(HH^{\mathsf T}+10^{-4}I)^{-1}E$. The resulting $h(x)W$ supplied visual input and output scoring vectors. The candidate bank comprised 7,990 distinct bitmaps after addition of training ink. A separate end vector completed the softmax. A selected cell supplied its own visual vector to the next causal step. The deployed model comprises 85.84 million transformer parameters, 9.44 million visual regression coefficients, a 0.50-million-parameter glyph metric, a fixed 2.36-million-coefficient projection, two boundary vectors and the bitmap bank. Its finite print inventory constrains the possible generated shapes.

We fitted the top four causal blocks and final normalization (28.35 million parameters) on two passes over 2,565 pictured DuReader examples, using AdamW, a batch size of at most 16 and a learning rate of $8\times10^{-5}$. The matched and shuffled fits each took 322 updates with the same ordered answer batches. Shuffling rotated complete passage--question pairs within length groups. The matched fit took 15.2 seconds and peaked at 2.08 GiB allocated GPU memory on one RTX 4090 D, excluding upstream pretraining, visual calibration and evaluation. The first-departure comparison added two passes at half that learning rate. We decoded greedily up to 48 cells and required an explicit end decision for exact credit. Conditional likelihood excludes one unwritable target in 14,860 decisions. Physical source membership uses all displayed cells, including one outside the writer bank. The evidence-window contrast kept the same decoder and used 224-character windows. The question-only BM25 ranker used normalized character unigrams and bigrams across windows in the original retrieved documents.
