\subsection*{Relative word-image context and passage completion}
Finite-context neural language models learn a distribution over the next word (Bengio et al., \url{https://www.jmlr.org/papers/v3/bengio03a.html}). PIXEL learns from masked rendered patches (Rust et al., \url{https://arxiv.org/abs/2207.06991}). Our auxiliary task hides an entire aligned word. Four relative offsets $(-2,-1,+1,+2)$ each supply a 50-dimensional physical word feature, a visibility indicator and a boundary indicator. A query network combines these observations with the frozen dialogue state. The passage-only head receives a zero dialogue state. The output distribution scores the existing 2,048 training-word prototypes. This finite output vocabulary does not cover every written form. During QA a learned gate combines retrieval with the inherited copy and glyph-spelling routes. The standalone gap interface receives separate left and right image strips; it never receives the missing word or its width.

We reserved the final 147 long CoQA stories in the original ordering before fitting. The four continuations used identical QA positions and masks. Each update included 16 uniformly sampled training turns with one random hidden position and 16 sampled multiword positions where the correct stored word was physically absent from all allowed copy edits. Cross entropy supervised retrieval directly against all prototypes on eligible positions. Binary cross entropy supervised the gate on the uniformly sampled portion. We mixed full masks, random masks and a single concealed word. The passage-trained arm added 64 window centres per update from fitting passages, giving 256,000 presentations and 230,157 distinct positions. Both visual arms had 896,983 parameters (322,833 updated). The passage-assisted visual fit took 33.1 seconds, 3.81 kJ and 366 MB peak allocated GPU memory on one RTX 4090~D. The four earlier fitting stages and the new preparation bring total measured device energy to 35.44 kJ, versus 34.04 kJ for the equivalent byte lineage. Host energy and offline corpus assembly are outside those totals.

For the passage test, every interior position counted in the denominator, including centres outside the writable memory. We also evaluated a count-based comparator on the identical fitting draws. It tries four flanks, the immediate flanking pair, the preceding word and then the following word, with a sampled unigram fallback. Two-sided pair and longer pattern estimates required two occurrences. For forward prediction it tries the previous pair before the previous word. Ties use prototype order. In an exploratory eight-word rollout the first 32 words of each story defined the prefix, of which the local predictor receives only the last two. Each subsequent input used the images emitted in the previous steps. The model has no learned stop in this fixed-length task. For a reached state $s$, let $c(s,y)$ count its desired remaining reference suffixes. A deterministic writer sharing that state can match at most $\sum_s\max_y c(s,y)$ suffixes. We proved in Lean that this bound is attained by choosing a modal suffix independently per state and that equality requires a modal choice in every observed state. A particular recurrent writer may attain less.
