\subsection*{Learning object pronouns from visual context}
For direct objects tagged as first, second or third person, we rendered the canonical English replies \textit{me}, \textit{you} and \textit{it}. A person tag alone does not determine an English referent. The canonical test therefore measures person, while the independent book evaluation retains contextual translations fixed before this change. We excluded identical printed windows across splits and all evaluation windows previously used to fit the writer. The training set contained 4,225 restored objects, 210 motion occurrences and 10,975 lexical examples. Motion windows received five additional presentations per pass in both arms. We fitted twelve passes through the frozen visual encoder and speller, adding a two-layer residual to the continuous contextual state. Gradients flowed through the speller to the residual. A quadratic penalty on the residual for the earlier lexical targets limited drift. The optical source reader retained its original states. The aligned fit took 9.70 seconds and consumed 0.92 kJ on the same RTX 4090 D. These are incremental fitting costs.

For each source partition we sorted the motion and third-person object windows of the same printed character by their content hashes, then paired them without replacement. Paired accuracy requires both stopped image outputs to match. An exchanged-answer control permuted targets within the central bitmap, preserving each glyph's marginal distribution in each training pass. The whole-passage transfer comparison held the reader's choices fixed and regenerated every possible source word in the passages.
