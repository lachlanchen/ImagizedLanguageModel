\noindent\textbf{Can a language model use the strokes of an unfamiliar character to write a faithful sentence? We extended a bilingual visual writer to accept new printed shapes, then trained matched models on 1,368 professionally reviewed Chinese--English translations. In one condition the reader saw each unfamiliar shape. In the other, it saw the same position and surrounding sentence with the ink hidden. On an external news test, exposing the strokes changed 93 of 96 answer images containing an unfamiliar shape. Neither fitted model earned a complete-meaning credit on those 96 requests. On 96 sources containing only familiar shapes both fitted models earned two credits, versus three for the parent. A wider visual input and a changed answer can therefore coexist with little usable translation.}\par
\begin{multicols}{2}
\section*{A continuous observation for every source cell}
Each input cell supplies 256 local ink densities from a $32\times32$ bitmap. Distinct unfamiliar cells receive temporary addresses so that the same learned optical network can process them. The phrase dictionary returns hints only for contiguous familiar runs. The output head selects printed English shapes from a fixed repertoire and learns when to stop. This experiment tests open input under aligned print and leaves open-ended drawing as a separate problem.
\end{multicols}

\section*{Matched training and held news}
The 1.82-million-parameter writer learned from 351 documents in WMT news and general translation evaluations and a TED suite, with earlier-corpus rehearsal. We reserved 192 pairs from 66 WMT 2017 documents before fitting. Each arm took 688 updates and received 1,173,391 target decisions. All 32 isolated CPU replays reproduced the original answers and stopping decisions. On the same external panel the source-only grader accepted 148/192 supplied references and zero displaced references. Its major-error rejection was poor in a separate professional calibration (Fig.~3). \repo{references/reviewed_news_writer_result.md}{Weights, original output images and all scores}.
\section*{Where the improvement ends}
Among 96 unfamiliar-source answers, training reduced repeated English word trigrams from 58 to 38. With the reference prefix supplied, the true source raised the reference score over an exchanged source on 92/96 requests. Yet the trained writer scored its own answer above the supplied translation on all 94 stopped paths. Thirty test sentences contained only unfamiliar shapes previously seen during fine-tuning, and 51 contained none seen during fine-tuning. Neither group earned a complete-meaning credit.
For two competing complete readings with counts $(a,b)$ and $(c,d)$ in two shape classes, suppose $a\ge b$ and $d\ge c$. Distinguishing the shapes increases the optimal number of correct readings by exactly $\min(a-b,d-c)$ over merging them. The bound concerns an optimal decision with other evidence held fixed. A learned writer need not attain it. \repo{formal/span_list/UnfamiliarInkEvidence.lean}{Lean proof}.
\end{multicols}
