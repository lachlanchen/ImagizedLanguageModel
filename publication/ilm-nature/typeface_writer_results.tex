\paragraph{A learned correspondence recovers answers in a second printed script.}
Changing both the question and source to Kai script had eliminated all 72 regular-print successes on the corresponding 192 questions. Keeping physical source positions available for copying, we trained a second visual route to recognize printed forms of the same glyph. With all language weights fixed, attaching this route alone recovered 65/192 Kai replies. Replay on alternate print alone gave eight. Combining correspondence and replay gave 72, including 13/96 passages with both questions correct (Fig.~\ref{fig:typeface-writer}). The same writer gave 77/196 exact answers in regular print and 78/196 in bold.

Transfer to HanaMin, an entire family withheld from adaptation, was weaker. The combined model gave 13/196 exact replies on the original questions and 15/394 on further trial questions, with zero complete two-question passages in either cohort. Alternate-typeface replay gave three individual answers in each cohort. The first extra passage gained by the combined model asked for a fish's common name. The first error supplied the name of a game in response to a question about losing the last life. In the additional HanaMin inputs, 106,216 of 158,717 glyph occurrences followed the correct correspondence or already matched the canonical bitmap, 45,882 triggered abstention and 6,619 selected a different identity. Erasing the HanaMin development questions yielded zero exact combined-model answers. The model missed the prespecified criterion for replacing the existing writer across typefaces.

The same weights gave 192/192 familiar historical replies and 54/192 after rephrasing. Of 188 distinct historical bitmaps outside the fixed inventory, the correspondence abstained on 187. Open answers requiring a glyph absent from the input remained at zero of 300. A separate offline catalogue indexes 2,315 headwords and 6,267 stage attestations. From an evidence card containing two headwords, the released writer returned the bronze and oracle forms of \textit{zhong} with the requested labels and order, matching the archived B00616 and J00887 bitmaps on CPU.

Supplying the correct regular-print embedding for each unambiguous, representable HanaMin input raised the mapped writer's trial score from 15 to 95/394, with 13 complete passages. This diagnostic retains the original source pixels and physical output choices. From text, Qwen3-8B Q8 gave 142 exact answers and passed 33/197 passages. Warm batch-one serving on the same GPU averaged 71 ms per mapped image request and 264 ms for the text model. The two systems operated at different accuracies.

On newly assembled catalogue cards for 100 additional headwords, the mapped writer answered both orders exactly for 100 headwords with familiar Chinese wording, 9 with rephrasing and 0 with the request printed in HanaMin. English requests asking for Chinese labels gave 0 complete order pairs. Retrieval provides the attested evidence and the writer must still read the requested order and stop.
