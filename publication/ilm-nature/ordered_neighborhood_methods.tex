\paragraph{Local reading and control of physical writing.}
Each matched reader added a zero-initialized residual computed from eight ordered cells to its passage state. Each had 2,675,523 parameters and saw 571,512 training windows over 2,980 updates. A matched arm shuffled the local inputs during training. Both fits including setup took 55.7 seconds and used at most 295.4 MiB of allocated GPU memory on one RTX 4090 D. These figures exclude earlier training. We scored every emitted pixel, length and stop on 3,895 held-out passage groups.

For a known target image sequence $y$, we maximized its physical path log likelihood $\log p_\theta(y,\mathrm{stop}\mid z)$ with fixed writer weights $\theta$ and $z=\tanh u$, using 100 Adam steps at learning rate 0.08. The two-state variant changed the supplied state after two glyphs and preserved the recurrent history. For a shared controller we learned $z_t=f_\phi(y_t)$, from 112 measured image features through two 512-unit hidden layers. It updated the writing state at each glyph and retained the fourth state for termination. We trained the 419,232 parameters for 100 epochs, weighting each of the 3,845 distinct expressions equally. Shuffling the assigned input expression each epoch yielded one complete training expression and zero unseen combinations. To test composition, we independently permuted the four columns of training glyphs and excluded duplicate and previously observed strings. These synthetic strings test the writer's ability to place supplied images in unfamiliar orders. They carry no judgement of linguistic validity.

In the boundary intervention both arms masked stop, retained four search paths within each glyph and committed one path at its end. The carry arm retained its hidden state, last pattern and measured output pixels. The reset arm initialized the hidden state from the next image, set the previous pattern to the start symbol and cleared feedback. No weights changed. We compared their identical first-position outputs before examining full-string accuracy. Externally supplying four positions precludes an inference about stopping.
