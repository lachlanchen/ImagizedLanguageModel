\subsection*{Question-dependent event positions}
We extracted all identifiable single-cell verb--object arcs with eligible glosses from the pinned Kyoto treebank. Distinct registered events within the same line required different endpoints, action names and answers. We grouped examples by rendered page and removed conflicting annotations or splits. For evaluation we screened each complete page and all 17-cell target windows against inherited training ink and the new training pages. The training split contained 28,148 clauses, including 3,864 with several eligible events. We reserved 336 multi-event clauses from held works, 635 from other held sections and ten contiguous extracts from the Chinese text of Pu Songling. Each literary object sense was registered before model execution without independent human adjudication. A treebank gloss can depart from an idiomatic translation. Scores refer to the registered readings.\footnote{Kyoto University, \textit{Classical Chinese Universal Dependencies treebank}, release 2.16, \url{https://github.com/UniversalDependencies/UD_Classical_Chinese-Kyoto/tree/r2.16}.}

Let $v$ and $o$ index visible cells. The score for an ordered pair was $A(v,o)+8s(q,v)$. The term $A$ includes 0.2 times the frozen syntax score, learned endpoint scores, a bilinear interaction and a signed-distance bias. The visual question similarity $s$ pools the maximum dot product between a corrected predicate key and the positionwise English question representation. Invalid cells and self-arcs are masked. The new head starts with zero corrections and contains 65,427 trainable parameters. Conditional cross-entropy normalizes over all admissible pairs. For each verb, the highest-scoring object is independent of the additive question term. Comparing those per-verb maxima gives a joint maximizer; Lean checks this factorization for integer scores. Inference passes the selected position to the recurrent image writer. The complete system has 3,592,031 parameters. Both page and question use 32-pixel rendered cells.

Each of 1,600 AdamW steps sampled 48 multi-event and 16 single-event pages with replacement. Within a sampled page we chose one event and one training frame. The control cyclically exchanged object positions in multi-event training examples. The aligned and exchanged fits took 6.72 and 6.12 seconds on one RTX 4090 D after 6.23 seconds to prepare frozen states. These are incremental costs. The second comparison added a supervised WordNet description view while retaining the literal target and the same source schedule. At most 16 associations per action and two training frames per association were eligible. The exchanged-description control shuffled eligible second views within each batch. An exact prompt-overlap check stopped an initial preparation before optimization. We recorded the collisions and used other training frames for those strings in both fits. Inherited readers may previously have seen individual words and descriptions. Each score requires success on every event in a page under both held questions. We decoded output strips against the printed English alphabet and required the exact registered verb cell, object cell, a stopped image and an accepted complete object word. Repeated windows within a held work and shared question families limit statistical independence.
