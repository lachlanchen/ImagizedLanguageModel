# Chinese idiom writing from pictured context

This checkpoint contains a 2,115,971-parameter reader and writer. It predicts an omitted expression between two pieces of pictured Chinese prose. It was trained on 71,439 candidate-free ChID windows and uses a learned physical renderer. The model has a single cloze task. It does not generate an explanation of an idiom.

With NumPy, PyTorch, Pillow, fontTools and safetensors available, run from the repository root. The example is a published validation case. Its reference and model output are 轻举妄动.

```bash
PYTHONPATH=. python -m scripts.infer_pictured_idiom \
  --weights models/pictured_idiom_zh/reader_writer.safetensors \
  --before-text '否雄起，还要看政策、全球经济等多方脸色，我们不敢' \
  --after-text '。灵活操作依然是首选。”一保险资产管理公司的负责' \
  --output /tmp/ilm-idiom-answer
```

The command writes `answer.png`, packed `answer.bin`, and a stop receipt. It runs on CPU. Typed Chinese uses Noto Sans CJK to render the input. Existing black-on-white 32-pixel cells can be passed as `--before-image` and `--after-image`; each side uses up to 24 cells. All answer pixels are generated by the checkpoint. No corpus, search engine, candidate list or output font is used at inference.

The model got 134 exact complete answers on 22,907 validation gaps. Exchanging the contexts yielded 23. A local training-count baseline yielded 1,012. The trained reader can also be evaluated against supplied answers, which is a different deployment. See the [full results](../../references/pictured_idiom_result.md) and [corpus description](https://aclanthology.org/P19-1075/).
